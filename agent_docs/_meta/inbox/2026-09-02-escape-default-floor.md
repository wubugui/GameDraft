# 逃逸辐射缺省从纯黑改为地板色(floor 0.3)

- 库内说法:`escape.py` 模块头引制作人 2026-09-01「默认就是黑色纯色」;`character-lighting.md` 与 A7 折叠一节也以"烘焙逃逸是黑"为前提。
- 现实:2026-09-02 制作人对四类走样修法说「选择最合适的搞」,按取证(深潭绝地沟壑带:纯黑逃逸把 probe 处半球反差放大到 18~49x,L2 截断残差压过背光侧真值)把缺省定为 `floor`(场景辐射中位 x0.3、画面平均色度),显式 `black` 仍可选。`resolve_escape` 烘焙时解析成 color 写进 baked_params。
- 已同步:`character-lighting.md` 硬契约新增四条(floor / 查询法线偏移 0.525 格 / 纵向密度 4 / 逐颗去环);A7 折叠一节的"逃逸是黑"措辞未改(折叠动机仍成立,只是暗侧不再是绝对零)。
