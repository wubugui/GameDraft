# 挂点测试硬编码假指纹，被 1×1 单帧包撞穿

- **现象**：新增单帧静态动画包后，`test_socket_panel_flow.py` 两条 stale 用例失败（"指纹对不上必须判失效"）。
- **真因**：fixture 取"排序后第一个有图集的包"，被新包 `baiwuchang_anim` 抢到第一位；
  而用例里的"假指纹"硬写死 `{"cols":1,"rows":1,"slotCount":1}` —— 单帧包本身就是 1×1×1，指纹反而**对上了**。
- **已修**：加 `_mismatched_atlas_fingerprint()` 从当前包算出再故意错开。
  **教训：测"对不上"的用例不许硬编码具体值，必须从被测对象派生。**
