现象: 机制卡里「脚点锚必须与深度图同源」只写给了 deferred 阴影,而同一病灶在角色/热点遮挡、planar 阴影落地面、`SceneDepthSystem.isCollision` 碰撞格反投影三处都还留着 `floor_depth_A/B` 拟合直线;更上游的问题是地面掩膜本身脏——旧口径「朝上 + 从画面底部 2D 洪泛」把屋顶当地面(屋顶既朝上又与街面 2D 连通),而 `stage_calibrate` 的目标函数就在这张掩膜上算,掩膜脏 = 视差→深度的 (a,b) 从一开始就偏,事后补救无效。
证据: 雾津街头掩膜污染 13.2%、地形高度场上蹲着十来个"山包"(建筑被烘进地形),屋脊那一列的地形深度 −1.562 比前方街面 −1.486 还近;改成「SAM3 实例分割扣物体 → 剩余像素定地面 → 调和外推 → 反解 d_walk」后污染 13.2%→1.3%、阎王岭 7.4%→0.2%,山地起伏保住(Yg p95 +0.189 vs 城镇 +0.051)。**但纯语义不能单独用**:temple 这类暗色室内没有可用门槛(0.15 吃掉 55% 真地板、0.35 留 42% 污染),必须与几何判据取交集。
建议: 机制卡把「脚点锚同源」升格为遮挡/阴影/碰撞三处并列的不变量,并记下三条新事实——①地面掩膜 = 语义(SAM 物体补集) ∩ 几何(朝上+洪泛),两路各有盲区(语义在暗室内过切、几何在 41.4° 以上陡坡失效),**都不能删**;②运行时无 `lighting/ground_d.png` 时遮挡/碰撞/影子裁切一律**关闭**而非回落旧模型(旧的 floor 直线口径与 `tools/scene_depth_editor` 已整体删除);③精灵深度代理为**直立 quad @ 行走面脚点深度**(`depth_per_sy = tanθ/ppu` 是其梯度),与实验室 CHAR_FS 的 billboard 口径不同——这是本次拍板的分歧点,若日后看到上半身 pop-through 再议。另新增两件设施应入库:`./dev.sh audit-depth`(三处落点一致性体检,已抓出 mountain_pass 标定与资产尺寸不符)、实验室「⟳ 重算地形+体检」(0.7s 快通道,跳过标定网格搜索;**不含可走掩膜**,那仍需完整重烘)。
