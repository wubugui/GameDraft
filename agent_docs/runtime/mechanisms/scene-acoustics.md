## 是什么（一句话）

场景回音**实时算**，不烘焙：一份「声学空间」→ 冲激响应（IR）→ `ConvolverNode`。
改一个数字立刻重算，毫秒级。

**只做实时，不做离线烘焙**（制作人 2026-09-07 定）：两套实现必然漂移。
同理，游戏内 F2 面板就是编辑器本身，**预览即成品**，不存在第二条实现路径。

## 数据在哪

| 层 | 文件 | 谁改 |
|---|---|---|
| 空间库 | `public/assets/data/acoustic_spaces.json` | 游戏内 F2「声学」页（有存盘按钮，自动 `.bak`） |
| 场景绑定 | 场景 JSON 的 `acousticSpace` | 主编辑器场景属性页的 **IdRefSelector** |
| 逐条开关 | `audio_config.json` 条目的 `spatial: {wet, dry}` | 手写 / 音频加工台 |

**一个空间可被多个场景引用**。缺省（不写 `acousticSpace`）＝没有空间，
空间音退化为纯干声，与加这套之前完全一致。

## 与视觉几何**解耦**（硬规矩）

场景 `worldWidth` 是**可行走范围**，不是画里的世界——跑马梁世界盒约 23 米，
而画上对岸崖壁在几百米外。**拿碰撞盒尺寸算声学必然算出一个小房间。**
声学空间是作者数据，按听感调，几何只在恰好可用时当参考。

与光影同构：原画就是最终光照，运行时不重新照亮。

## 三条硬判据（都是踩出来的）

1. **最近反射面的延迟必须大于干声时长**，否则回音压在原声上，
   听着像院子不像山谷。猿啼 3 秒 ⇒ 最近面要 500 米以上（往返）。
   F2 面板按当前干声算出这个下限并提示。
2. **晚期尾必须延后到第一次反射之后**。从 0 时刻起会把原声与回音之间那段
   空白填满，而**那段空白正是山谷感的来源**。
3. **别硬套点源 `1/r` 衰减**：760 米往返按 1 米参考算是 −57 dB，
   实测整条 IR 沉到 −99 dBFS 等于没有。崖壁是大反射面，
   走**立体角项**（面积/L²）并钳上限。

物理只管两件事，因为错了就假：**延迟 `2d/c`**（`c = 331.3 + 0.606×℃`）
与**空气对高频的吸收随距离增大**。后者才是「远」的听感来源——
**远 = 发闷，不是变轻**（山谷最远抽头 4kHz 只剩不到 1%）。

## 模型：平面摆放 + 高度（不是完整三维）

反射面 = 俯视平面上的线段 + 高度 + 底高程，单位米。听者位置是活的（见下）。

| 得到 | 放弃 |
|---|---|
| 距离 → 延迟 | 任意倾角的斜面（只有竖直/水平两类） |
| 方位角 → 真实声像 | 复杂多边形的精确求交 |
| 面积 → 立体角 → 强度 | 仰角的**声像**（立体声输出渲染不了） |
| 高程差 → 路径变长、水平面反射 | |
| 俯视二维射线 → 遮挡 | |

固定视角、立体声输出，为「仰角声像」上完整三维不划算；
但**高程本身要算**——它决定路径长度，也决定水平面（水/檐）存不存在。

## 运行时接线

```
                       ┌─→ dryGain ─────────────┐
BufferSource ─→ vol ──┤                         ├─→ Howler.masterGain
                       └─→ wetGain → Convolver ─┘
```

- **一个场景一个 Convolver**，所有空间音共用；换场景换 IR。
- **不碰 Howler 内部节点**（够 `sound._node` 是私有实现，升级即碎）：
  空间音走**并行的原生 Web Audio 通道**，BGM / 环境 / UI / 未标 `spatial` 的音效
  一律仍走 Howler，两条汇到同一个 `masterGain`。
- **环境底噪不要开 `spatial`**：底噪本身就是这个空间，再加混响是重复。
- 自带回音/距离感的素材（远处孤鸟、深潭远闷、带回音的喊叫）**不许标 `spatial`**，
  会叠两层。

## 校验

`scene.acousticSpace` → 空间库的引用**运行时不报错、不回落**，写错一个字
只是那个场景彻底没有回音、毫无痕迹。因此 `tools/editor/validator.py` 的
`check_acoustic_space_ref` 把未知键记 **error**（不是 warning）。
抽成纯函数是为了让「能不能真抓到错」本身可被单测断言——
用整个 `validate()` 去测需要完整 ProjectModel，测不动就只能 skip，
而 skip 掉的恰恰是这道门唯一的价值。

## 活听者（2026-09-08 补）

**听者钉死在原点＝走到崖边和站在路中间是同一个回音，实时就没意义了。**
场景 JSON 的 `acousticListener` 决定听者跟谁：

| mode | 含义 |
|---|---|
| `player`（缺省，不落键） | 跟玩家 |
| `camera` | 跟相机（镜头拉远、人很小的场景更贴合画面感受） |
| `entity` + `entityId` | 跟指定 NPC；那个 NPC 不在本场景时**回落到玩家**（不静默变哑） |
| `fixed` | 钉在空间里作者摆的那个点 |

场景世界坐标（wu）→ 声学米制走 `sceneToAcoustic`：`anchor` 给原点、
`wuPerMeter` 给尺度（缺省 88，来自尺度锚「角色高 150 wu」）。
⚠ 场景 y 轴向下、声学 z 轴向前，换算里翻一次符号。

### 重算的两道节流（不做就是每帧掉两帧）

重算一次 IR 实测 6–50ms（随 IR 长度），主线程同步做。所以：

- **移动阈值按空间尺度自适应**：`最近反射面距离 × 0.04 × 代价因子`，钳在 2–25m。
  山谷里挪 3 米对 300 米外的反射面毫无影响，纯属白算；棺龛墙那种 8 米的空间
  挪 3 米就很要紧。代价因子让贵的空间要求挪得更多，自平衡。
- **最小间隔 300ms**。
- 超出 25ms 预算会 `console.warn` 一次（只一次，不刷屏），并在 F2 面板状态行标 ⚠。

### 三处性能优化（改之前 93ms）

1. **晚期尾缓存**：尾巴内容与听者位置无关，只有起始偏移变。
   重生成 21.6 万样本×2 每样本一次 `exp` 要 75ms。
2. **尾部裁剪**：低于峰值 -80dB 的余数切掉（山谷 IR 10.34s → 5.6s），
   拷进 AudioBuffer 的开销与长度成正比。
3. **峰值边写边记**，省掉两遍全量扫描（各约 9ms）。

⚠ `buildImpulseResponse` **默认返回拷贝**。`transient: true` 才给暂存视图，
只有立刻 `set()` 进 AudioBuffer 的热路径该用 —— 「拿两条 IR 做对比、
第二条把第一条覆盖了」是典型的静默失效，默认必须安全（单测钉死了这条）。

## 仰角与遮挡（2026-09-08 补）

- **反射面分两类**：`tiltDeg < 45` 是竖直崖壁（默认），`>= 45` 视作**水平面**
  —— 脚下的深潭水面、头顶的岩檐。水平面的镜像在 y 上，路径就是上下走一个来回。
- **竖直面的仰角**只在一处真正起作用：面覆盖 `[y, y+height]`，听者不在这个区间
  内时反射点被钳到边缘，路径随之变长 —— 头顶那片崖壁确实比平齐的远。
  平齐时 y 抵消，耳高不影响结果（有单测钉死）。
- **遮挡**是俯视二维线段求交：听者到反射面中点的直线被别的竖直面挡住就衰减。
  一层去掉七成，两层以上基本听不见；**不做硬剔除**，边界处不会「啪」地消失。
  `occlusion: false` 可关。

## 已知边界

- 立体声输出渲染不了仰角，`tap.elevation` 目前只用于诊断与水平面判定。
- 遮挡只看竖直面，不看水平面（水面不挡横向的声音）。
- 声源恒与听者同位（自己喊）；「远处有个东西在响」还没做。
- **不支持手机端**（制作人 2026-09-07 决定不做移动端）。
