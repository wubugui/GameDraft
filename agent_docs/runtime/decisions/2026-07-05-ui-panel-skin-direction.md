## 背景(一段)

2026-07-05 首次定稿为「民俗草根·极简、纯程序化零素材」。2026-08-03 制作人重画了整套设计稿
(`tmp/ui_mockups_2026-08-03/`),基调仍是民俗草根·极简,但**明确要求了材质**——旧木框、纸纹底、
金细线,原零素材路线随之作废。

## 决定(一句)

游戏内面板 = **民俗草根 · 做旧木框**:纸纹底 + 厚做旧木条外框 + 木框内侧一圈暗金细线 + 暗角 +
拉开字距的琥珀标题 + 选中态「点亮一档琥珀」而非换深色;全部经
[ui-panel-skin](../mechanisms/ui-panel-skin.md) 单一入口铺开。
**标题界面是另一套语言**(海报:全出血主视觉 + 无框菜单列),刻意不走面板皮
—— 制作人原话「不要一板一眼的面板」「之前的设计稿太老土了」。
版式(2026-08-05 从三版对照图里选定):**标题压左上、菜单左下竖排、全部左对齐**;
**不许有任何满屏压暗**——压暗等于把美术再抹一层,可读性一律交给字自己的投影。
两种语言各司其职,别互相同化:标题是海报,游戏内面板是钉在墙上的木牌。
底图是**带透视的氛围立绘**,与「可行走场景背景去素材库挑现成、禁 AI 生成」那条无关
——那条只管可行走场景背景,**不是禁止 AI 出美术**(本项目美术全是 AI 生成的)。

## 被否方案(防翻案)

- **纯程序化零素材 / 不用九宫格贴图 / 不要金线**(旧稿三条,2026-08-03 推翻):现用两张贴图,
  九宫格木框已采用,内侧暗金细线已采用——但仍**只是一条线,不是勾花**。
- **雕木繁复 / 满符箓 / 印章 / 云纹角**:仍然否。木框是素旧木条,出图工具偶发加雕饰一律不采用。
- **标题界面套用面板皮**:2026-08-04 明确否。半透明底板也算面板,同否。
- **底部渐变 scrim / 任何满屏压暗**:2026-08-05 否(曾用过);居中收紧、右下右对齐两版同否。
  改回居中式或重新加压暗前先问制作人。
- 正文楷体 + 标题报隶:反了。定稿为**标题楷体 / 正文宋体**(报隶在 hero 字号下笔画发圆像 POP 体)。
  仍是系统字,上线前须换可商用打包字体。
- 小圆角近方正仍然成立(radius 2~4)。
