## 背景(一段)

规划期曾立红线"对话立绘选择必须缩略图网格弹窗、禁止长下拉";2026-07 立绘编辑器
实际落地为"三态下拉 + 表情下拉 + 72px 预览"并经实机使用,两者字面冲突。2026-07-11
首轮建库审批时制作人裁定普适边界原则,取代按控件个案立法。

## 决定(一句)

只有列表很短的枚举才允许用下拉;其它一切(大候选集、跨文件引用、视觉资产选择)
必须走弹窗选择器。

## 被否方案(防翻案)

- "立绘一律缩略图网格弹窗"按字面执行(短枚举也强制弹窗)——被普适原则取代;
  三态/表情这类短枚举下拉合规。
- 长下拉承载大候选集或引用选择——禁止;现存违规按编辑器待办逐个清理,
  不因"已经这么写了"而追认。

## 清理进度(滚动)

- **音频那批已清完**(2026-08-10):六个音频选择点收敛到统一的音频弹窗选择器
  (搜索 + 时长/文件/状态列 + 键盘走带试听),护栏已钉住"不许再出现巨型下拉"。
  踩到的四条 PyQt 死路记在
  [共享选择器控件保值契约](../mechanisms/shared-widget-value-fidelity.md)。
  **顺带一条形状**:选择器基类里"该不该走弹窗"的判定曾因 `editable=True` 恒为假,
  于是**弹窗路径根本走不到**——违规不一定长得像违规,可能是开关被另一个属性关死了。
- **图对话编辑器读叙事图的那处 graphId 也已清**(2026-08-27,原为 40+ 候选的可编辑长下拉,
  且"校验放行的候选选择器却不列"——见
  [图对话编辑器卡](../mechanisms/dialogue-graph-editor.md) 的 14b)。
- **剩下的账不是某个控件,是没有门**:"引用字段禁长下拉"应列进该卡逐类型点名的界面 parity
  检查,否则新出现的违规只能靠人肉发现,而上面两处都是**别的事故顺带发现的**。
