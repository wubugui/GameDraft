# 叙事调试器

给策划用的独立调试器。回答三个问题，别的一概不管：

1. **戏走到哪了** —— 左栏拍子清单，游戏在哪一拍就亮哪一拍
2. **现在在哪儿、前面后面是哪儿** —— 中间的焦点邻域图（只画焦点前后几步，不画全图）
3. **我刚才那一下，系统听见没** —— 右栏人话时间线（听见了 / 没人听 / 条件挡住了）

外加一件事：**回到任意一拍**（读那一拍的全量存档，世界状态精确回溯，不是推状态机）。

## 怎么用

```bash
./dev.sh narrative-debugger
```

然后在游戏地址后面加 `?ndbg=1`：<http://localhost:5173/?ndbg=1&mode=dev>

两边自动接上。就这两步，没有第三步。

端口被占了就 `./dev.sh narrative-debugger --port 5212`，游戏那边相应加 `&ndbg_port=5212`。

## 界面上的东西

| 位置 | 是什么 |
|---|---|
| 左栏 | 先选哪条线（主线／几条活计），下面是那条线的拍子。`▶`＝游戏正在这拍，`●`＝有存档点，`◐`＝档是补记的、回去可能落在这拍后面，`○`＝这张图改过、档可能对不上，`✕`＝这一拍整段都在演出里，没能记上 |
| 中间图 | 焦点前后各 N 步。单击换焦点往前后探路，双击回到那一拍。蓝框＝你在看的，绿框＝游戏停在这儿，实线＝同一条线，虚线＝会带动另一条线 |
| 「在等」框 | 这一拍要往下走，**玩家具体该做什么、在哪个场景、找谁**（追到对话／区域／压力条／小游戏为止，不是"等某子图走完"） |
| 右栏 | 时间线。一个玩家动作一行：**点物／找人／走进区域／按压力条／进小游戏／开对话**都记，后面跟上系统认没认。认了说走到哪，没认说是悬垂、条件挡住、还是根本没往叙事里传 |
| 自动记点 | 默认开。每走到新的一拍自动存一份全量档；演出中存不上会重试，实在存不上会当场说 |
| 假装做了那一下 | 按人话搜一件事，直接标成已发生，用来验后面的路通不通 |
| 信号关系… | 一条信号**谁发、谁听**，外加此刻谁真在等（下面单开一节） |
| 存档点… | 看／删存了哪些点，一键清掉过期的 |
| 重新读一遍数据 | 在编辑器里改完 JSON 点这个，不用关掉重开（会记住你正看哪条线） |

## 「信号关系」窗：我刚才那一下怎么没反应

工具栏 `信号关系…`，或者**双击时间线里那一行**（直接落到那条信号）。

左边是全部信号，每行前面的圆点是**此刻**的状态：

| 圆点 | 意思 |
|---|---|
| ● | 现在真有转移在等这一下（起点对上、没条件挡、这条线也在跑）|
| ◐ | 起点对上了，但**还挂着条件**，或者这条活计现在挂起着——打出去不一定动 |
| ○ | 有人听，但那些图现在都不在起点那一拍 |
| · | 根本没有转移听它 |
| ⚠ | 两侧对不齐（没人发 / 没人听 / 没登记 / 广播没开）|

判定口径跟运行时对齐：活计图只有在它是**当前激活**的那一个时才吃信号
（`NarrativeStateManager.listScannableGraphEntries`），挂起的活计一条信号都不接；
条件满不满足静态数据判不出来，所以只说"挂着条件"，不替运行时打包票。
游戏没连上时圆点一律降级——那时它说的是最后一次连着的世界，不是此刻。

两个勾选框把清单缩到能用的范围：`只看现在能推动的`（排查"点了没反应"先看这个）、
`只看两侧对不齐的`（数据本身就断了）。搜索框搜的不只是 id——**发它的那段戏、听它的那张图**
都能搜到，因为策划记得住的通常是"婆子那段发的那个信号"。

右边一条信号说五件事：

1. **现在** —— 有几条路正等着这一下，等在哪张图的哪一拍；没人等就直说"打出去多半没反应"。
2. **玩家要做的那一下** —— 去哪个场景、找谁、点什么（一路下钻到玩家真动手那一步）。
3. **谁发的** —— 全工程的实际发射点（对话图哪个节点、场景哪个热点、哪份内容资产）。
4. **谁在听** —— 每条转移一行，前面同样是 ●/◐/○/·，并写清它此刻为什么不动
   （挂着什么条件 / 活计挂起了 / 停在别的拍）；点一下**镜头挪到那一拍**（不动游戏）。
5. **本次会话** —— 这条信号这次跑起来出现过几次、每次的结果（听见了/被条件挡了/没人听）。

底下两颗按钮：`在图上看这一拍`（只挪镜头）、`就当这件事发生了`（真把信号打出去；
没连上游戏、或者是 `__draft__` 占位时按钮是灰的，不给人点一个必然没用的东西）。

数据口径来自 `tools/narrative_xref`（与主编辑器的「信号关系」面板同一套扫描，两边永远
说同一件事）。主窗点「重新读一遍数据」时这个窗会跟着换新，不会拿旧关系骗人。

## 对运行时的影响：四道闸

工具不开的时候，游戏侧**什么都不跑**：

1. **编译期** —— 探针整块包在 `import.meta.env.DEV` 里，prod build 由 Rollup 静态剔除
2. **启动开关** —— dev 下也默认关，没有 `?ndbg=1` 就不建连接
3. **热路径** —— 引擎挂点是 `NarrativeStateManager.traceObserver?.(...)`，
   未连接时一次静态属性读，不分配对象；`transition.blocked` 埋点只在连上时才执行
4. **异步** —— 全部 fire-and-forget，微任务合批（不靠 setInterval，后台标签页会被节流），
   send 失败静默丢弃，绝不 throw 回游戏逻辑

除玩家主动点「回到某一拍/发信号」外，探针只读，不写任何游戏状态。

## 引擎侧一共动了四处

| 位置 | 改了什么 |
|---|---|
| `src/dev/narrativeDebugBridge.ts` | 新文件，整个探针 |
| `NarrativeStateManager` | `traceObserver` 静态挂点 + `transition.blocked` 埋点 + `failingConditionIndexes` |
| `ActionExecutor` | `actionObserver` 静态挂点（唯一执行入口，只读一次静态属性） |
| `SaveManager` | `capturePayload` / `loadPayload` / `canSaveNow`（复用原 load 的校验与回滚路径） |
| `Game` | dev-only 装配 + destroy 摘钩 + 订阅四个既有事件（`hotspot:triggered` / `npc:interact` / `dialogue:start` / `zone:enter`） |

装配点在 dev 启动直达路由**之前**：`?narrative_warp=` 会 await 一长串状态推进，装在后面的话直奔某一拍时调试器连不上（实测踩过）。

## agent 也能用（MCP）

调试器同时是 MCP 后端。在 `.mcp.json` 里挂上之后，agent 和策划**共享同一份状态**——
agent 跳一拍，策划屏幕上焦点跟着动。

```json
{"mcpServers": {"narrative-debugger": {
  "command": ".tools/venv/bin/python",
  "args": ["-m", "tools.narrative_debugger.mcp_server"]}}}
```

工具：`narrative_state` / `narrative_waiting` / `narrative_timeline` / `narrative_beats` /
`narrative_goto` / `narrative_emit` / `narrative_capture` / `narrative_signal_info`。

## 存档点放哪

`resources/editor_projects/editor_data/narrative_debugger/savepoints/`。

不占玩家的三个存档槽，也不进 localStorage。

每份档带**它所属那张图**的指纹（不是整个文件的）——改一张图只让那张图的档变灰（`○`），
不会因为改了个错别字就让所有点集体失效。标灰的意义：那种"读了档但状态机停在已删除的
状态"是最难查的脏局，宁可提醒一句。

记点范围＝状态数 ≥3 的图（各线主图、`scenario_*` 那些戏、活计），不记 `wrap_读人`
这类二值开关——全记的话一次推进能攒几十份全量档，列表里全是策划不认识的名字。

## 已知边界

- **粒度是一拍，不是一句台词**。对话/演出进行中存不了档，这不是闸门保守：那些系统的
  `serialize` 本来就不持久化在途状态。
- **「再演一遍这段戏」＝读档 + 重设同一状态**。读档只回滚世界（`deserialize` 不跑
  `onEnterActions`），所以后面补一次 `setState`——它走 `enterState`，会把这一拍的演出
  原样重跑。读档在前，保证副作用不叠加。
- **补记的档会标出来**。演出中存不上、等结束才补记时，戏可能已经走过这一拍，
  那份档就不是这一拍的现场——左栏标 `◐`、tooltip 说明、读回去时提示条也说一遍，
  标记随档一起落盘（重开工具还在）。不假装准。
- **「再演一遍这段戏」演的是你正看着的那一拍**（图中间蓝框那个），不是游戏当前那拍——
  想重看的多半是刚过去那段，焦点已经指过去了。
- **回退只在同一条故事线里找**。绝不跨线——把人从背尸活计扔到码头那条线上，
  比不给回退更耽误事。
- **没存过档的拍子只能硬跳**，世界前置（身上的东西、场景变化、任务进度）不跟着回去，
  画面可能对不上。界面上会明说，不假装精确。
- `__draft__` 出口是编辑器的合法占位，界面上显示「这条路还没接线」，图上不画、清单里不排。
- 少数出口仍答不出地点（梦境那段、部分捞箱小游戏）——查不到就照实说，不编。
- 命令通道的 `debugTriggerHotspot` 绕过 `InteractionSystem`，所以脚本触发的热点
  不会出现在"你点了什么"里；真人玩的时候会。
