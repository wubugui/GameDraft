推给游戏 / 导出到游戏有什么区别？
推给游戏：页面上此刻的涂层（存没存都算）烘一份预览，在跑着的游戏里原地换上——资源一个字节不动。
导出到游戏：先存盘，再烘进资源（各时段照明载荷目录），发行包里就是这一份。
动起来什么样去游戏里看——工作台只管抠图与标注，游戏是预览器。

锚点 / 整体摆怎么用？
锚点：左键放、右键删最近的一个。刚体部分绕离它最近的锚点转——点在竿底 / 树干底； 一丛竹子可以每根竿点一个。没点就绕自动算出的根。
整体摆：左键点一株切换（右键拖照常擦当前层）。标了的整株一起弯，不会被扭成波浪（全场的波浪尺寸在游戏 F2 里调）。
这两样和涂层一起 Ctrl+S 保存；改完不用先存，「推给游戏」就能在游戏里看。
刚体到底干什么？
刚体 = 竹竿 / 树干这类只能整体摇晃、不许跟着扭的部位。分割认出的木质已自动算刚体， 「减刚体」用来抹掉认错的那些。四层各画各的：橡皮只擦当前这一层，右键拖随时擦，不会碰到别的层。
刚体 = 不弯，但跟着转：涂了的地方不会被扭成波浪，整块绕离它最近的锚点（没点锚点就绕自动算的根）一起转。 想让一块完全不动，用「锁死不动」（石头、崖壁同一待遇，原画那块原样留着）。
· 细竿也管用：刚体与叶子的交界处网格会自动加密，过渡带约 6（竿两侧这么宽的叶子跟着竿硬一点），其余地方不加密。
· 点了两个以上锚点的株，锚点之间的分界也会加密，两边各绕各的锚点转。
· 笔刷软边上的刚体度不是满的（软硬拉到 100 涂得最干净）；涂在没抠出植被的地方（石头 / 锁死区 / 空地）会被丢掉。
· 整株刚转的树（Alt+点显示「整株刚转」）本来整株就是刚体，在上面涂刚体只会去掉叶片细抖。

夜景 / 其他时段怎么处理？
夜晚没有单独的 mask，设计上就是用白天这份。这里只显示主背景（白天），涂一次管所有时段。
每次推给游戏 / 导出到游戏：
1. 抠植被与拆层只按主背景跑一次（自动分割 + 涂层 + 锁定图 + 锚点 / 整体摆）， matte / ids / rigid / sway.json 逐字节原样写进每个时段的目录——草木长在哪不随时段变，暗的夜图也分割不出来。
2. 底板每个时段各补各的：白天的 mask 定"补哪些像素、从哪取"，拿该时段自己的原画去填，夜里植物晃开露出来的是夜景颜色。
3. 打光场景里，每个时段还会各自重建漏出处的几何件（扣掉植物的法线 / 深度等）。
注意：
· 时段原画必须与主背景同尺寸、逐像素对齐。尺寸不同会跳过并在日志里说；同尺寸但内容错位，夜里 mask 边缘就对不上。
· 没有照明载荷的时段不出摆动，那个时段草木不动——先给那张图烘 scene_fields 再回来导出。
· 时段原画里植物本身变了（夜图多画 / 少画 / 形状不同），这套管线不支持，要做成每时段各自的 mask 才行。
日志里每个时段写了还是跳过、为什么跳过，都会列出来。
