画布上选中任何东西（一个点也算、整段、整条、点幽灵 = 整条）就出现 gizmo：W 移动（沿轴箭头 / 面片 / 中心）· E 旋转（圆环）· R 缩放（轴末端单轴 / 中心等比），2D 与 3D 视图同一套；拖动时按住 Ctrl 吸附。这里的数值框是精修用。

曲线原点

原点 = 这条曲线自己的参考点：帧相对它写，播放时给的位置对齐的就是它；场景曲线不给位置就在它这儿原地播。 它不是第一帧——调运动起点只改"起点相对原点的偏移"，曲线其余部分与播放位置的关系一个 wu 都不动。拖它不会动曲线；"整条"变换会带着它一起走。

命名插槽

点行选中；拖它或拖 gizmo 挪位置；Delete 删
插槽 = 这条曲线暴露给场景的位置（人站位、接钱的人站位……）。其他动作（角色移动 / 瞬移 / 临时演员生成点）用"曲线 X 的插槽 Y"引用它，引用是活的。播放曲线本身不挪任何东西。曲线没有锚点：播放位置在播放时给。
