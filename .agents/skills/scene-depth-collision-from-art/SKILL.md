# 从原画做碰撞 + 深度(固定流程)

> 知识在库里,**先读完再动手**:深度标定与塌平面的来龙去脉 `agent_docs/asset-pipeline/mechanisms/scene-bake-downstream.md`(「已知坑」④);
> 碰撞口径 `agent_docs/editor-tools/recipes/collision-from-art.md`;作者层与重投 `agent_docs/editor-tools/mechanisms/terrain-workbench.md`。
> 本技能只管怎么做。命令前加 `PYTHONIOENCODING=utf-8`;下文 `AR` = `sh scripts/py.sh -m tools.terrain_workbench.art_review`,
> `REDO` = `sh scripts/py.sh -m tools.character_lighting_lab.redo_depth`。产物默认在 `local/collision_review/<场景>/`。

## 为什么是这个顺序(一句话)

碰撞第一轮只看画,**画面上哪里是路**不依赖深度;深度标定反过来拿这些路当"水平地面"、路以外的表面当"竖直立面",
俯角和远近比例一起算出来;深度对了,第二轮才能用**游戏真实的深度遮挡**去核"物体后面的地"开得对不对。
两边互为检验:第二轮对不上的地方,要么碰撞估错了,要么深度错了,回画上判是哪一样。

## 五条硬规矩

1. **第一轮碰撞只看画**,不看深度(那时深度还没标定,可能整张是错的)。照 `scene-collision-from-art` 第 1~5 步做。
2. **深度只能用 `REDO` 重做**:它按顺序跑完 钉作者多边形画面轮廓 → 烘焙 + 导出 → 作者多边形落回新几何 → 夜等时段载荷用新几何重起
   → 几何场 → 草木 → 深度体检。**别单跑 `pipeline.py`**:少一步不报错,碰撞整片错位 / 夜里角色浮空 / 法线还是旧的。
3. **深度只有 `AR depthsheet` 过了才作第二轮的依据**(见第 4 步过关标准)。塌平(朝向图处处一个灰)的深度一律不信。
4. **不拿碰撞凑深度,也不拿深度凑碰撞**:第二轮对不上时回原画判;深度错就修深度(实验室物体涂层 / 深度笔刷,或回第 3 步换标定),
   不去挪碰撞让它"看起来对"。俯角、比例一律由标定算,不手调参数凑图。
5. **一个场景同一时间只归一个人写**;交付必带改前 / 改后的 `depthsheet` 图和第二轮摆人图。

## 八步

### 0. 前提
- 场景 JSON 在、主背景在;时段原画(夜等)与主背景**逐像素对齐**(尺寸不同 `REDO` 会在时段那步停下)。
- 从没烘过的场景:先 `REDO <场景> --calibration level`(给碰撞工具一个能反投的几何;它会跳过碰撞相关步骤)。

### 1. 改前留档
- `AR depthsheet <场景> --out local/collision_review/<场景>/depthsheet_before.png`(有深度才有)、`AR render <场景>`。
- 看 `depthsheet` 的 JSON:`collapsed: true` / 朝向图一片灰 = 现在的深度是塌的——这正是要修的。

### 2. 碰撞第一轮(只看画)
- 照 `scene-collision-from-art` 第 1~5 步:圈 walk(能站的地)、可走区里的物体圈 block + h,`AR check` 退出码 0,摆人图(缺省 `--occlusion h`)过。
- **这一轮的 walk 就是下一步标定的"地面"**:只圈真的地面(路面、台阶面、院坝),别把墙根、崖面圈进去——圈进去的立面会把深度拉斜。

### 3. 选标定方式
- **structure(立面约束)**:画里除了路、物体、远景之外,基本都是**竖直**的墙 / 崖壁 / 房子立面——峭壁栈道、街巷、院墙。
  近乎平视看峭壁、路很窄的画**必须**用它(level 在那上面塌成一块斜板)。
- **level(自动找平)**:大片缓坡山体、斜屋顶没被物体识别扣掉、室内地板占满画面——"路以外都是竖墙"不成立的画。
- 拿不准:先 structure,第 4 步看数;立面偏离竖直中位 > 15° 或路面坡度中位 > 25° = 这张不合 structure 的假设,改 level 重跑并在回报里写明。

### 4. 重做深度
- `REDO <场景> --calibration structure`(或 level)。约 5~20 分钟一张(探针烘焙是大头);**多场景串行**,别并行。
- **过关**(全部满足才往下):
  - 退出码 0,日志里 `[calib] structure:` 那行的俯角 / 路面坡度 / 立面偏离是"落盘深度复算"的数;
  - `depthsheet`:`collapsed: false`、路面坡度中位 < 25°(爬坡石阶的图可以到 20° 上下)、立面偏离竖直中位 < 15°;
  - **看图**:朝向图上路是白带、墙 / 崖是黑的;深度图近红远蓝,前后关系与原画一致(近处崖面红、远处深谷蓝)。
- 不过:先看是不是第 2 步把立面圈进了 walk、物体掩膜漏了大块结构(实验室物体涂层补);再考虑第 3 步换标定。

### 5. 碰撞第二轮(游戏真实深度遮挡)
- 分块 `AR crowd <场景> --occlusion both --x0 … --y0 … --x1 … --y1 …`:人按**游戏真实深度**被挡掉一截(与运行时同式)。
  - **品红圈** = 作者估的遮挡(block 的占地 + h)与深度遮挡差得多;JSON `disagree` 列坐标和两边各挡了几成。
  - **红圈** = 脚被深度挡住 = 游戏里这个人站在某个东西后面。原画上他前面确实有东西(房后那条街、护栏后的路)= 对;前面是空地 = 深度错。
- 每个圈回原画判是哪一样,各自的改法:
  - 物体占地 / h 估错 → 改那块 block(`AR footprint` / `AR region` 同 id 重写);
  - "物体后面的地"开错 / 漏开 → 改 walk;**改了 walk = 改了标定用的地面 → 回第 4 步重跑 `REDO`**(实验室会提示几何签名变了),
    重跑后只复查改动附近那一片;
  - 深度那一块错 → 修深度(实验室物体涂层 / 深度笔刷后回第 4 步),或列进回报,别动碰撞。
- `AR check <场景>` 仍须退出码 0(重投后的连通、落点、交互、孤岛)。
- **收敛**:walk 没改就不重烘;改了 walk 最多再重烘一次,第二次还有同一处对不上 → 停下列进回报,别来回拉锯。

### 6. 独立复查(必须做)
- 新起子代理,给它 `scene-collision-from-art` 的「复查协议」原文,**再加一句**:
  「另跑 `crowd <场景> --occlusion both`(分块、`--out` 到你自己的目录),把品红圈 / 红圈逐个回画判:遮挡对不对、是碰撞错还是深度错。」
- 它只报不改;按它报的局部补丁改完,让它只看改过的那一片,直到"无问题"。

### 7. 真机验
- 起游戏(`?mode=dev`),进场景:玩家站到几处物体后面 / 前面截图(遮挡对)、夜景切一次(载荷没丢)、火把照路面。
- 落雷 / 粒子依赖真实表面的,抽查一次(`strikeThreat` 无靶落点候选 > 0,见 `agent_docs/runtime/mechanisms/strike-threat.md`)。

### 8. 收尾
- `sh scripts/py.sh -m tools.terrain_workbench --check <场景>`、`audit_walkable --reach`、`validate-data`(只看有没有新增 error)。
- 回报制作人(**以图为主**):改前 / 改后 `depthsheet` 并排、第二轮摆人图、俯角、开放了的"物体后面的地"位置、第 5 步停下没收敛的点。

## 已知坑

- **重做深度 = 作者多边形错位**:`REDO` 已含 `pin-screen` / `reanchor`;作者层里有**笔刷层 / 高度修补**(栅格,没有画面轮廓)`reanchor` 会停,
  先在地形工作台里改成多边形。
- **structure 的数值极限**:最优解可能落在"深度 ∝ 视差"的线性极限,映射已改写成不会溢出的形式,标定末尾用落盘深度复算自检;
  自检报错 = 这张图不能用这组结果,别绕过。
- **草木拆层要本机离线的 SAM3 权重**,没有就在 `sway` 那步失败(先按 `scene-bake-downstream` 首条坑预下载),其余步骤已完成、别整条重跑,`REDO <场景> --skip pin,build,reanchor,phases,fields` 补跑。
- 画面最边上可能留几粒与主路断开的小可走碎块(`check` 的 `smallIslands`),不挨出生点 / 出口就不影响;细护栏比网格窄只落实七八成(`finerThanGrid`)。
- 实验室「标定方式」下拉框显示的就是这张图用的标定;structure 下俯角 / 起伏增益两根滑条置灰(由拟合定)。
