## 需要仔细检查的项目(人工 / 子代理审查)

**A. 引擎核心语义(对 Pixi 8.17 源码逐条比)**
- 变换:局部 / 世界矩阵、pivot / anchor / skew、世界矩阵版本缓存的失效条件、toGlobal/toLocal、getBounds / getLocalBounds、
  sortableChildren / zIndex、addChildAt / swap / reparent、destroy 选项(children / texture / textureSource)与事件。
- 渲染树:visible / renderable / alpha / tint / blendMode 的继承与合批打断、culling(cullable / cullArea)、onRender、
  isRenderGroup / cacheAsTexture(若被用到)、setActive 与 visible 的分工。
- 合批与管线:纹理槽上限、混合模式(含非预乘纹理的混合变体)、roundPixels、模板遮罩嵌套 / 反向遮罩 / 精灵遮罩、
  颜色掩码、滤镜链(bounds / padding / resolution / antialias / clipToViewport / filterArea)、RT 渲染(clear / clearColor /
  transform / 嵌套 render)、generateTexture / extract、背景清屏。
- 资源:纹理上传(image / canvas / video / buffer、预乘、alphaMode、mipmap、更新 updateId / resourceId)、纹理与缓冲的释放
  (切场景后 GPU 资源不增长)、采样器(addressMode / scaleMode)、UniformGroup 的 UBO 布局与动态更新、Geometry 动态更新。
- 图形 / 文字 / 精灵:GraphicsContext 全部指令(含渐变、描边对齐、圆角、贝塞尔、洞)、Text(中文字体、换行、描边、投影、
  字距 / 行高、resolution、动态改字)、HTMLText、NineSlice、Mesh、Texture 的 frame / trim / rotate / defaultAnchor。
- 事件:hitTest / hitArea / eventMode / interactiveChildren / cursor / pointer capture / 拖拽 / 滚轮 / 多点、事件顺序与冒泡、
  坐标换算(resolution / autoDensity / 画布 CSS 缩放)。
- 应用:Ticker 优先级与 deltaTime / maxFPS / 暂停、ResizePlugin(resizeTo、0 尺寸)、Application.destroy、渲染抛错守护。

**B. RHI**
- 资源作用域与延迟释放(录制期销毁、跨帧)、只读 / 只写约束、readback、渲染图剔除与瞬时池、设备丢失、诊断上报、
  画布尺寸 / 零面积、MSAA(新)、管线就绪与 skippedDraws。

**C. 着色器移植(GLSL → WGSL)**
- 每个移植着色器逐分支对 master 的 GLSL:uniform 布局 / 默认值、纹理 y 朝向(WebGPU 第 0 行在上)、采样(Level / Grad /
  整数坐标)、精度 / 除零 / pow 负底 / NaN、宏开关与变体、铁律 0(光照一律世界空间)。重点是 render_parity 用例**没覆盖**的
  参数组合与分支。

**D. 游戏侧行为**
- 实体在场改 setActive:所有读在场的地方(交互、气泡、阴影、光照、VFX 锚点、排序、调试、存档无关)与 master 同义;
  隐藏期间动画 / onRender / 组件是否该停。
- Game.ts:揭幕前闸(管线就绪)、诊断、renderer.init 参数、切场景 / 销毁流程、冻结期 eventMode。
- 小游戏(水、糖画、纸扎、物件查看 / 接触 AO / 小虫)、演出(视差、过场叠层、渐变、燃烧、呼吸)、UI(滚动遮罩、按钮命中、
  输入框、Toast、书架 / 书页)、光照(时段外观、实体灯、probe、阴影、GI)、VFX(粒子 / 光柱 / 雷)。
- 性能:帧时间、每帧分配、draw 数、切场景后内存 / GPU 资源不涨。
