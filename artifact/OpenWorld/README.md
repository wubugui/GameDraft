- 八处歇脚点、路牌和地方观察、条件显示的调查物件、三条可独立完成的街坊委托。重庆口语和民俗悬疑沿用现有基调。

最终补验：桥下水面中心被碰撞阻挡，两岸仍可行走；沿岸走到右岸出口并触发去河滩。路线点与门口另经静态碰撞采样检查。自动步行脚本在贴墙拐角有过停步，需要从当前位置重新规划，不以脚本首次成功率代替场景可达性。
