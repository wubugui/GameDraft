# 动画挂点系统 · 技术设计与落地注记

**日期** 2026-08-03 ｜ **状态** 已落地（第一/二档）｜ **范围** 运行时 + 编辑器 + 数据契约

---

## §0 一句话

给动画包定义命名挂点（右手 / 头顶 / 腰…），**逐帧**标注位置 + 角度 + 前后，
运行时可以往上挂任意图；数据住 sidecar `sockets.json`，产线永不触碰。

---

## §1 数据契约

`<动画包目录>/sockets.json`：

```json
{
  "schemaVersion": 1,
  "atlas": { "cols": 9, "rows": 10, "slotCount": 89 },
  "sockets": {
    "right_hand": {
      "label": "右手",
      "poses": {
        "0": { "x": 0.62, "y": 0.55, "angle": -12, "front": true, "frame": 2 }
      }
    }
  }
}
```

**为什么是 sidecar 而不是 anim.json 里的一个键**（2026-08-03 拍板）：

- anim.json 是**产线产物**（`export_gamedraft_anim*` 从零拼 dict），挂点是人工逐帧标的，
  生命周期不同。
- 更要紧的是——挂点按**图集槽位**索引，重导出后槽位会漂移。同日修好的
  `merge_preserved_anim_fields` 现在会把非产线的顶层键并回来，所以内联的 `sockets`
  **反而会被静默保留成错位数据**，比丢失更坏。sidecar + 独立指纹让失效**可检测**。

**为什么按图集槽位索引**：同一张图＝同一个手的位置。导出的 `dedup_merge` 会把相同帧
合并成一个槽位，正好强化了这条语义——一个槽位标一次，所有引用它的动作都受益。

**坐标口径**：格内归一化。`x` 0=格左 1=格右；`y` 0=格顶 1=格底（＝脚线）。
与 `states[*].bubbleAnchor` 同一套归一化，运行时按 worldWidth/worldHeight 换算。

## §2 失效检测（stale）

`atlas` 是**网格指纹：只有 cols / rows / slotCount**——这三个决定"槽位索引指向哪一格"。
加载时与 anim.json 比对，对不上就**整份判失效**：运行时忽略全部挂点并 warn，
编辑器亮橙色横幅提示重标，validator 报 error。

> **宁可不挂，也不照漂移的槽位号挂错位置。**

**刻意不含 cellWidth / cellHeight** 两条理由：
1. 格子像素尺寸变了而网格没变 = 图集只换了分辨率、槽位次序没动，格内归一化坐标依然成立，
   放进指纹是误杀；
2. 这两个值在 TS 侧经 `normalizeAnimationSetDef` 由纹理推导补全、编辑器侧读的是原始 JSON，
   放进指纹会让两侧对同一个包算出不同答案——全库有 8 个包没写 cellWidth，
   会因此"运行时永远判失效、编辑器横幅永远不亮"（2026-08-03 验收抓到）。

⚠ **已知且刻意的边界**：重抠图但网格没变**检测不出来**——那种情况得靠人重看一遍。

## §3 运行时

**位姿解算**是纯函数 `socketPoseToLocal`（[animationSockets.ts](src/data/animationSockets.ts)），
穿过五层变换：

1. 帧格归一化 → 世界尺寸
2. 透视系数（近大远小，挂件同步缩）
3. 镜像（x 翻到另一侧，角度取反）
4. 跳跃视觉抬升
5. 实例 scale/rotation（挂件是容器子节点，天然继承）

抽成纯函数是因为**编辑器画布要用同一处**，否则会出现"编辑器里对齐了、游戏里差半个身位"。
Python 侧有逐值镜像 `animation_sockets.socket_pose_to_local`，由
`test_socket_pose_parity.py` 与 TS 侧钉死同一组黄金数值。

**挂载**：挂件是 `SpriteEntity.container` 的子节点，因此

- 天然继承实体位置，跟角色一起吃场景深度遮挡（滤镜挂在容器上）；
- **前后**由子节点顺序决定：`front` 排到最后（身前），否则插到最前（身后）。
  ⚠ 启用光照时 `sprite` 只当变换载体、`litQuad.mesh` 才出图，两者是兄弟——
  "身后"必须插在**两者之前**，不能夹中间。

**同步点**挂在 `applySpriteScale`（所有换帧/换向/透视的必经点）与 `setVisualLiftY` 上。

**某帧没标注 = 挂件隐藏**（既不乱摆也不卸下）：像"刀在鞘里那几帧手上没东西"，
标注缺席就是它该消失的意思。

**生命周期**：`SpriteEntity` 只摘不毁（挂件资源归调用方）；`Game` 持有挂件的 Sprite，
切场景收场景实体的、`destroy` 收全部。玩家跨场景存活，它的挂件留着。

## §4 两档能力（2026-08-03 拍板：先做前两档）

| 档 | 数据 | 代价 |
|---|---|---|
| **① 静态图** | 一张 PNG | 挂点已给位置+角度，刀随手挥、灯笼随身晃已经会动 |
| **② 挂点驱动帧号** | 一列 PNG + 标注里的 `frame` | 火苗能烧；**不引入第二个时钟**，因此没有锁相问题 |
| ③ 完整 SpriteEntity | 一整个动画包 | **未做**：多一个时钟要定跟谁走、首次挂载异步会闪、资产成本翻倍 |

第三档等真出现"角色站着但灯笼还在晃"这类需求再开。

## §5 编辑器

anim 编辑器新增「挂点」折叠区（默认折叠）：

- 左：挂点列表（增删）
- 中：帧画布——点/拖挪位置、拖橙色手柄转角度、实心圈=身前空心=身后、洋葱皮显示上一帧
- 右：按动作过帧（只列该动作用到的槽位）、前后/角度/挂件帧号

**省力工具是可行性前提而不是锦上添花**——全库 46 个包、3176 个图集槽位：
复制上一帧 / 本帧铺满本动作空帧 / 本动作内线性插值（已标注的都不覆盖）。

**例行反馈走状态行、不弹模态**：模态 `exec()` 在无人值守环境会永久阻塞，
本仓库已有一条测试因此挂死（`test_assign_group_write_and_undo`），不再制造第二条。

**存盘**：只写 sidecar，脏态并进 anim 编辑器（保存/放弃/关闭走同一条门）。
整份为空时**删文件**，不留空壳。

## §6 动作（内容侧入口）

| 动作 | 参数 |
|---|---|
| `attachToSocket` | `target`（实体，已登记 ENTITY_REF_PARAMS）、`socket`、`image` 或 `images`、`scale`、`anchorX`、`anchorY`、`rotation`、`mirror`、`lit` |
| `detachFromSocket` | `target`、`socket` |

四件套齐：运行时 `register` + `actionParamManifest` + 编辑器 `ACTION_TYPES`/`_PARAM_SCHEMAS`
+ `ENTITY_REF_PARAMS`（第五件，含实体引用）。

**挂点管姿态、挂件管自己**（2026-08-04 补）——两组参数职责不同，别混：

| 谁 | 管什么 | 标在哪 |
|---|---|---|
| 挂点标注 | 手在哪、手转到什么角度 | anim 编辑器逐帧，全包共用 |
| `anchorX/anchorY` | 这张图的哪个点算"被握住的地方"（刀=刀柄 `0.5/0.92`，灯笼=提环 `0.5/0.05`） | 动作参数，随挂件走 |
| `rotation` | 修正**画的时候**朝向（图是竖着画的、挂点却按横握标） | 动作参数，随挂件走 |
| `scale` | 挂件相对角色的大小 | 动作参数，随挂件走 |

一句话：同一个 `right_hand` 挂点，换把刀不该重标挂点，只该换这三个数。
缺省 `anchorX=anchorY=0.5`（图心），`rotation=0`，`scale=1`。

镜像时 `rotation` 与挂点角度**一起取反**，否则角色转身道具会拧成反的
（真机实测：朝右 x=2.7 rot=1°，朝左 x=−2.7 rot=−1°，逐值对称）。

数值靠肉眼调，所以 F2「挂点」页给了四条实时滑条（缩放/支点 x/支点 y/自转），
直接改已挂上去那件的属性、下一帧生效。

## §6.5 挂件预设（2026-08-04）——这三个数不该住在动作里

上面那张表的右三行（支点/自转/缩放）描述的是**挂件自己**，不是某一次挂载。
写在每个 `attachToSocket` 调用点上有两个后果：要重敲，且**必然发散**——
五处挂剑迟早有一处数字不一样，而且没有任何机制能发现。

所以搬了家：`public/assets/data/prop_presets.json` 登记一次，动作只写 `prop: "taomu_jian"`。

```json
{
  "taomu_jian": {
    "label": "桃木剑",
    "image": "/resources/runtime/images/props/taomu_jian.png",
    "anchorX": 0.79, "anchorY": 0.16, "rotation": 0, "scale": 0.5
  }
}
```

**合并规则**：显式给了用显式的，没给用预设的（`??` 不是 `||`——`anchorX: 0`
是合法值，用 `||` 会被吃掉，已有回归钉死）。贴图**整体替换**不逐项合并：
给了 `image`/`images` 就是"这次换张图"，和预设的图拼起来只会拼出谁也没想要的序列。

**坏条目逐条丢弃**而不是整份失败——与 `sockets.json` 的"整份判失效"相反：
那边槽位错位是系统性的，这边条目之间互不相干，一个挂件写错不该让别的挂件全挂不上。

**编辑器**：「数据编辑 → 资源与本地化 → 挂件预设」。主从列表 + 详情，
右侧是**试挂预览**——选动画包/挂点/帧/朝向，把挂件按真实位姿摆到角色帧上，
橙色十字标出支点。位姿走 `animation_sockets.socket_pose_to_local`（与运行时同一套数学、
parity 测试钉死），缩放按 `scale * k * cellW / worldWidth` 换算（挂件不继承
`sprite.scale`，见 §3）。表单与预览**左右并排**：调这三个数全靠盯着预览拖滑条，
上下摆会逼人来回滚动，等于把这页唯一的价值弄没了。

改名会扫全工程 `attachToSocket.prop` 并可跟随改写；删除前先报引用清单
（`prop_preset_refs.py`，复用 `signal_refactor.CONDITION_SOURCES` 那张容器登记表，
不另抄一份）。

**F2**：「挂点」页把工程里真有的预设排在硬编码 demo 图前面，按预设挂会把预设值
同步进滑条——于是"编辑器调好 → 游戏里按预设试挂 → 微调 → 抄回"是连着的一条路。

## §6.6 顺手挖出来的一个真往返 bug（2026-08-04）

给 `attachToSocket` 加完参数后探了一次往返，发现**打开一个含挂件的过场再保存，
会被写上 `anchorX: 0, anchorY: 0, scale: 0, rotation: 0, mirror: false, lit: false`**。
这不是格式漂移，是**改行为**：支点从图心跳到贴图左上角、光照关掉、翻面关掉——
全项目的挂件一次点保存全毁。根因是泛型控件的中性值（数值 0 / 复选框未勾）
被当成了用户的选择。

三处修法：

1. **数值**进 `_ACTION_PARAM_RUNTIME_DEFAULTS`（该表从 `int` 放宽到 `float`），
   按**真实缺省** seed 控件（支点 0.5、缩放 1）而不是 0。附带好处：打开就看得见
   "支点现在在图心"，不用猜 0 是什么意思；且显式写 `anchorX: 0` 仍然写得出来。
2. **`mirror`/`lit`** 运行时默认 `true`，而复选框中性态是 `false`——用 bool 控件
   就**配不出**"不镜像/不吃光"（一律当没设剔掉）。改走 `playNpcAnimation.loop`
   的三态惯例（`""`/`"true"`/`"false"` 下拉），落库时还原成真 bool。
3. **`image`/`prop`** 的"缺省即未设"只对 `attachToSocket` 成立——`image` 在
   `showOverlayImage`/`setHotspotDisplayImage` 是 required+nonEmpty。
   按名的全局剔除表会误伤，所以新加了一张按 `(action, param)` 限定作用域的
   `_ACTION_SCOPED_OMIT_WHEN_ABSENT_AND_DEFAULT`。

⚠ **给 action 加可选参数时，务必探一次"最小形态打开→保存"**——
往返测试只测了"给了值的字段保不保值"，测不到"没给值的字段有没有被凭空注入"。

## §7.5 踩实的一个坑：可选 sidecar 的存在性探测

`sockets.json` 绝大多数包都没有，所以加载必须"没有就安静跳过"。**但在这个 dev server 上
"文件不存在"不是 404**——Vite 的 SPA fallback 对任何匹配不到的路径回 **200 + index.html**
（实测 `GET …/sockets.json` → `200 text/html`）。

于是"先探 `res.ok` 再载"这条常识写法直接失效：探测放行 → `response.json()` 撞 `<!DOCTYPE`
抛错 → 落进 `AssetManager.loadIntoBucket` 的 `reportDevError` → DEV 红条每进一个场景刷一屏，
且失败不入缓存，每实例化一个实体重来一次。

**判据必须是 content-type，不是状态码。** 见 `AssetManager.loadOptionalJson`
与 `AssetManager.test.ts` 里那条 "200 + text/html 当作不存在" 的回归。

## §7.6 F2「挂点」调试页

真机目验没有工具就做不动——四个预设（桃木剑/灯笼/伞/符）+ 一只鸡（从 `chicken_anim`
图集里现裁 24–29 槽，验第二档的多帧挂件），加挂点下拉、四条挂件滑条、
临时挂点位姿三条滑条。

**两个踩过的坑**：

1. **默认挂到哪**：最初一律挂到内置的 `TEMP_SOCKET`，那是一个常数位姿的调试挂点——
   于是"挂上去的东西是静止的"，看起来像挂点系统没跟帧，其实是页面挑错了挂点。
   现在默认选**本包第一个真实挂点**，`TEMP_SOCKET` 排最后。
2. **临时挂点不能覆盖真挂点**：注入调试挂点时是叠加，不是替换整份 `sockets`，
   否则一开调试页就把这个包标好的挂点全盖没了。
