## 0. 三条改造原则

**一、剧情不动。** 每一拍发生什么、谁出场、结局如何，全部保持 `Demo完整流程_2026.06.05.md` 的编排。改的只是"玩家这一拍手上在干什么"。

**二、不是每一拍都是完整循环。** 三种拍型：

| 拍型 | 干什么 | 玩家的手 |
|---|---|---|
| **播种拍** | 只产象、埋理，不解决问题 | 看、闻、问、翻档案 |
| **循环拍** | 完整跑一遍 象→(理/术)→行动→回写 | 判断准备够没够、挑术、承担代价 |
| **叙事拍** | 纯剧情，不塞玩法 | 推进 |

全是循环拍会把玩家累死，而且理和术**没有地方提前埋**——那个"闲话里早就拿到了"的瞬间就没了。节奏必须是：播种 → 小循环 → 播种 → 大循环。

**三、背尸不是玩法，背尸是象的产地。** 关二狗的本行不该做成体力 QTE。它的作用是：**每背一具尸，就是一次贴身观察的机会**——尸的轻重、干湿、味道、僵不僵，全是象。规矩在这条线上被反复检验。

**四、先建立信任，再打破它。**（2026-07-26 制作人纠正）

「规矩可能是假的」这件事**绝不能在开局引入**。玩家还没相信"规矩管用"之前就给他假货，那不是反转，是让他判定整套系统不可靠，直接放弃机制。

**推翻的前置条件（通用编排规则，不止 Demo）**：

> 一条规矩被推翻之前，玩家必须**已经至少完整掌握并亲手验证过 2 条真规矩**，且其中至少 1 条是**他自己吃亏换来的**（不是听来的）。

而且推翻的最佳时机不是"随便某个后面"，是**玩家最得意的那一刻**——他刚连着办成几桩事、刚开始真信自己有两下子。此时手里最风光的那条规矩是假的，才叫拐点。

**顺带教一件事**：Demo 里玩家验证成功的（R2、R8）都是**自己经手挣来的**，被推翻的（R9）是**听说书的听来的**。这个对照不需要一句台词，玩家自己会咂摸出来——这就是全作主题。

### A · 背尸行当的门道（关二狗的真本事）

**R1「淹死的，水汽重」** `jargon`
- **象**：管事顺嘴点的——淹死的泡过水，上了肩往水那头坠，背着走莫沿水边
- **理**：水汽勾水汽；**且淹死的认物不认人，他的东西在哪儿，他就摸得到哪儿**
- **术**：改道离水走；遗物归主（送回停尸处，报一声出处，不能烧不能扔）
- 出处：义庄管事

**R2「上肩莫换肩」** `jargon`
- **象**：老背尸的都说，一趟只上一次肩，宁可歇死也莫换
- **理**：换肩那一下，尸身要重新找位置——**它会"醒"一下**
- **术**：走之前就把路算好，中途只停不换；真要换，得先落凳、报一声
- 出处：零工工头 / 义庄管事

**R3「干尸才走」** `ward` ← **本 Demo 唯一被推翻旧规矩后诞生的新规矩**

- **理**：白毛是受潮生的霉，跟凶不凶不搭界；**要命的是干不干——干尸才走得动**
- **术**：**让它重新湿**（泼水、盖湿布、等雨）；**灭火而不是加火**
- 出处：瞎子李 / 赶尸匠手札（钱买不到，只能从懂行的人那儿来）

**R4「镇尸四样」** `ward`

- **术**：亲手用过，管用；**但不知道是哪一样起的作用**（存疑）

## 2. 逐拍改造

### ⓪ 听书（茶馆）· **播种拍**

**剧情不动**：说书人讲李天狗大战旱魃，关二狗没点茶被小二撵出去。

**玩法结构**：玩家第一次接触规矩本。**这一拍不给假规矩**（见 §0 原则四）。

- **产象**：瞎子李在旁边搭话（"哪有恁个容易的事哦"），算一卦，给 **R7「莫走夜路」的象**
- **R7 的性质**：**真的，但 Demo 内用不上**——理层和术层都不解锁
- **说书人这一拍只给 lore**（李天狗大战旱魃进见闻录），**不给规矩**

**教学意图**：
1. 第一次看见"规矩本新增"，学会"听来的东西会进本子"
2. **而且第一条就是暂时用不上的**——教玩家"本子里会有你现在不懂有啥用的东西"，为后面"闲话里早就拿到了"那个体验打底
3. **不教"规矩可能是假的"**。那要等到 ②。

**手上做什么**：听（推进对话）+ 追问（花钱/说好话换细节）。追问决定见闻录里那段李天狗的故事有多完整——**这段故事后面会在 ② 变成他吹牛的弹药**。

### ① 背崖墓尸 · **循环拍（教学循环）**

**剧情不动**：庄家结阴婚，不腐女尸穿嫁衣，没人敢接，关二狗接了；架尸、腿软两次、和那张脸打照面、闻到香粉味、吓跑。

**玩法结构**：**第一个完整循环，但故意让玩家"什么都没有"**——教玩家"没准备是什么滋味"。

| 环节 | 内容 |
|---|---|
| **象** | 进灵堂就有：这尸**该塌不塌、该烂不烂、该臭没臭**。玩家此刻手里一条相关规矩都没有 |
| **入口** | 停尸的门板。**这一拍入口无条件显形**（教学拍，不能卡） |
| **理/术** | **全无**。玩家想找也找不到——庄家人不肯多说，义庄管事还没认识 |
| **行动** | 只能硬上：上肩、走。中途尸变重，他换了一次肩（**此时他不知道 R2**） |
| **结果** | 半成中最差那档：腿软两次、和脸打照面、闻到香粉味、扔下工钱就跑 |
| **回写** | **不产生任何验证**——他跑了，没办成。**但产出两个象**：R2「上肩莫换肩」的象（换肩那一下尸"醒"了，他记住了这个感觉）、以及香粉味（**不入规矩本，阿秀信号永远不是规矩**） |

**教学意图**：让玩家亲身体会"两手空空去办事是什么下场"。这一拍的挫败是**设计好的**，而且它产出了 R2 的象——**玩家的第一条规矩，是自己吃亏换来的，不是听来的。**

> ⚠️ 阿秀信号（香粉味 + 小调）**永远不进规矩本、不参与象理术**。它是玩家永远无法"掌握"的东西——这条是红线。

### ①.5 街巷自由段 · **播种拍（主力播种场）**

**剧情不动**：踩铜板、摸橘子、抢饼结仇、偷鸡、踢狗踢猫、袍哥秒怂、壮汉撞人、街头闲话、瞎子李算命。

**玩法结构**：**这是全 Demo 埋理的主力场**，也是"闲话里早就拿到了"这个体验的产地。

| 播什么 | 埋在哪儿 |
|---|---|
| **R1 的象**（淹死的水汽重） | 街头闲话：脚夫抱怨昨天那具"离了水反而更沉，邪门" |
| **R6 的象**（路祭不能动） | 街头闲话：有人说野道边那摊路祭这两天被人动过 |
| **R8 的象**（先看谁看谁） | 叫花子斗嘴 / 袍哥秒怂：关二狗自己就是这么活下来的，**这条是他自带的，触发一次互动就写进本子** |
| **R7 的象** | 瞎子李算命（已有） |

**关键设计**：这些闲话**当时全都没用**。玩家听了就听了，本子里多几条不知道干啥的东西。等到 ③ 婆子家要读人、⑨ 路上撞见路祭、背尸活遇到淹尸——**他会发现自己早就有了。**

**手上做什么**：走、看、闻、搭话。**这一段应该允许玩家什么都不做直接走**——错过的人后面会更难，这是设计好的代价。

### 背尸零活链（路倒 / 淹尸）· **循环拍 ×2（复用训练场）**

**剧情不动**：找活 → 义庄门口拦活 → 破屋验尸 → 野道背回 → 义庄结钱。

**玩法结构**：**这是 R1/R2 的复用训练场**，也是玩家第一次尝到"有准备"的甜头。

**第一单（路倒 / 缢死）**
- **象**：验尸时看脖子——这具是缢死的，脖子上那道印子不对（产 R2 的理：为什么缢死的换肩最忌）
- **理**：从义庄管事嘴里拿 R2 的理（换肩那一下它会"醒"）
- **术**：R2 的术——路先算好，中途只停不换
- **行动**：野道那一段，路上有岔口、有坡、有水沟。**玩家自己决定歇几次、在哪儿歇**——不是 QTE，是**路线判断**
- **三档**：
  - 有 R2 象+理+术：一趟到底，管事全款结清，还多给两个钱
  - 只有象：走到一半肩疼，换了 → 尸"醒"一下（惊吓）→ 到了但工钱打折
  - 什么都没有：中途出事，可能落尸（不可逆：这具尸沾了土，管事扣钱且记你一笔）
- **回写**：R2 三层齐、标**有效**。**这是玩家第一条完整掌握并验过的规矩。**

**第二单（淹尸）**
- **象**：这具泡过水，上肩就往水那头坠（R1 的象在此坐实）
- **理**：管事那句"水汽勾水汽，莫沿水边"
- **术**：改道离水走
- **行动**：野道有两条路——沿河近，绕坡远。**玩家自己选。**
- **三档**：沿河 → 越走越沉，可能落尸 / 绕坡 → 远但稳
- **回写**：R1 的象标**有效**，理层还差一半（"认物不认人"那半要到别处拿）

> **复用点**：R2 在两单里都要用；R1 在第二单验证，理层留白到正篇。

### ② 茶馆吹牛 · **复用拍 + 假货投放点** ★

**剧情不动**：吹那趟背尸经历，越吹越大，扯师承李天狗；说书人返场讲飞僵段。

**玩法结构**：**前半复用 R8，后半塞给他那条假规矩。**

**前半 · 复用 R8**
- **打出 R8「先看谁看谁」**：吹牛时主动读场——谁在真听、谁在等着拆台
- **打出后不是行动**，是得到一条路："冲着那个听得最入神的说，别理拆台的"
- **行动**：吹牛的对话选择（原分支不动），但读过场的玩家看得见哪个选项是安全的
- **三档**：读了场 → 名声涨得快、还白喝了茶 / 没读 → 被当场拆穿一次、名声打折
- **回写**：R8 的术标**有效**

**后半 · 投放 R9（假的）** ★
- 此时玩家的账本上已经有：**R2 验过（自己吃亏挣的）+ R8 验过（刚刚用成的）**。前置条件满足（§0 原则四）
- 关二狗吹得正得意，说书人返场讲飞僵段，**顺口给他"白毛僵尸怕火"**
- 关二狗当场把它当宝——**这正好喂饱他"我是李天狗那一脉"的自我认知**
- 玩家侧的心理：我刚验成两条，规矩这东西管用；说书先生还是行家；**这条我记下了**
- **玩家可以追问**，追问越深，R9 的象层写得越详细。**⑨ 那一下就越疼**

> 这一拍是全 Demo 的钩子：玩家在信心最高的时候，白得一条最风光的规矩。而它是假的。

> - **钱从 `paid` 状态挪进对话分支**（三档金额不同）。

> 并锁住「三档都必须把主线推到 s04_pozi」。


**剧情不动**：婆子上门、院外读脸色、进屋念几句、宣布压住了、收钱、连夜跑；那家真的没事了（Axiu 挡的，玩家不知道）。

**玩法结构**：

| 环节 | 内容 |
|---|---|
| **象** | 院外那一站——谁最慌、谁一开口另一个先看过去。**没有 R8 的象，这些细节根本不会被高亮**，玩家只看见一院子人 |
| **入口** | 院门。有 R8 的象才显形"可以先站一会儿" |
| **理** | R8 的理：先看的人心里有鬼，**被看的才是事主** |
| **术** | R8 的术：把话对着事主说，越含糊越像 |
| **行动** | 进屋念那几句（从 ⓪ 听书那儿抄来的词）。**玩家自己挑对谁说、挑用哪几句** |
| **三档** | 有理有术 → 全额、口碑滚起来 / 只有象 → 说对了人但话说破了，钱拿到一半 / 硬上 → 对着最慌的那个说（错人），差点穿帮，**Axiu 挡了一下**，勉强收钱但婆子家从此不认他 |
| **回写** | R8 三层齐、标**有效**。玩家第一次尝到"骗人也是要本事的" |

> 注意：**Axiu 那一下永远不是玩家的功劳**，也不写进任何规矩。玩家越是硬上，越容易撞见她——但他读不出来。

### ④ 河边递纸 · **播种拍**

**剧情不动**：蹲着出恭，身后伸过来一只手递纸钱，回头没人。

**玩法结构**：**不做循环。**这一拍的功能是恐怖和 lore，塞进象理术会毁掉它。

- **唯一的玩法接触**：事后关二狗手里还攥着那沓纸钱。**这是一件实物**，可以拿去问人。
- **产象**：问出去之后，得到 **R6「路祭不能动」的理层的一半**——"人家给你的和人家摆的，是两码事"
- 玩家可以完全不问，那就只是一段吓人的经历

**这一拍教的是：象不一定在现场，可能在你事后拿着东西去问人的路上。**

### ⑤ 码头捞箱 · **叙事拍 + 轻播种**

**玩法结构**：**这一拍是洋人线的钩子，不是规矩线的。** 现有的水下段保留与否与本稿无关（那属于表现层）。

- **轻播种**：箱子里那本风水古籍复印件 → **档案系统**里多一本可读的书。**这本书后面是 R3「干尸才走」的理的备用来源之一**（如果玩家在 ⑨ 之前把它读了，⑨ 那一拍会容易得多）
- 这是"理可以提前很久拿到"的第二个演示，而且比闲话更硬——**你得真的翻开那本书读**

### ⑦ 枯井狗脸 · **播种拍**

**剧情不动**：街坊凑钱托他捞井里的"狗"，往下看，那不是狗的脸，对视一息，扔绳就跑。

**玩法结构**：**不做循环。**理由同 ④——这一拍的价值是"真·非人"的冲击，给它一套解法会把它变成可管理的东西，恐怖就没了。

- **玩法接触**：跑回来之后，**这桩事没解决**。街坊的钱你拿了，事没办。
- **产象**：R3 的象前半——**井里那东西是干的**。他扔绳下去的时候摸到了井壁，井是枯的，没有水。（这个细节在 ⑨ 会咬回来）
- **代价留痕**：拿了钱没办事，街坊那边记你一笔，后面几桩事的报价会低

**这一拍教的是：有些事你就是办不了，跑是对的。而跑掉留下的痕，是真的。**

### ⑧ 向导传闻 · 置办行头 · **叙事拍**

**玩法结构**：不塞象理术。这一拍是目标切换和经济压力。

- **唯一的机制接触**：**这是"代价永远不够用"（锁三）的兑现点**。前面几拍你省下来的钱、赚到的口碑，在这儿要拿去换行头。硬上省下的钱这时候还回来。

### ⑨ 阎王岭送货 + 林中喊名 + 柴棚 · **循环拍（Demo 最大的一拍）**

**剧情不动**：接脚力活、跟脚帮走、一路听闲扯、到岭口不敢进、返程天黑、林子里喊名、忍住不应、天亮下岭。

**玩法结构**：**三个循环串在一条路上，而且是全 Demo 唯一的推翻点。**

**第一段：一路听闲扯（播种）**
- 脚帮闲扯里给 **R5 的象**（山里喊名别应）和 **R6 的象**（路祭不能动）
- 玩家可以走神不听——那后面两段会非常难

**第二段：路祭（小循环，R6）**
- **象**：路标边那摊酒肉。饿了一天了
- **理**：动了就欠它一口
- **术**：绕开；已经动了就还上并且一声不吭
- **行动**：玩家自己决定吃不吃。**这里必须真的很饿**（前面代价花光了，没干粮）
- **三档**：绕开 → 无事 / 吃了但一声不吭 → 缠上但不重 / 吃了还骂两句 → **重度缠身，直接把第三段难度顶满**
- **回写**：R6 的理标有效（**吃了的人才拿得到这条理**——这是"亲历才有理"的最好演示）

**第三段：林中喊名（循环，R5）**
- **象**：一声一声"二狗——"
- **理**：那是杂气学人声
- **术**：闷头走不回头；**已经应了就从来路退回去**
- **行动**：**不是长按 QTE**。是路上有三个点，每个点声音的方位、语气不同——玩家判断"这一声该不该理"。有一声是真人（脚帮掉队的），**理错了会把真人丢在山里**（后患）
- **三档**：全判对 → 天亮下岭，只是耳朵里还响 / 判错但没应 → 惊吓 + 丢了同行的人 / 应了 → **濒死 → 死亡系绳（这一拍走"系绳失灵 + 李天狗外部接管"变体，剧情不动）**

**第四段：柴棚（循环，R9 推翻 → R3 诞生）** ★ **Demo 玩法高潮**
- **象**：野道边柴棚，火烧了一半，人不见了，地上一撮白毛。**有 R9 的象才认得出白毛，入口才显形**
- **硬上**：照 R9 加火 → **它站起来了** → 濒死 → 系绳 → 留痕 → **R9 标存疑**（还不知道错在哪）
- **盲试**：去买桃木符纸糯米黑狗血挨个试 → 钱花光、每试一样它离棚口近一点 → **不可逆，路开始关死**
- **搜理**：只有瞎子李 / 赶尸匠手札给得出——"白毛是霉，跟凶不搭界；干尸才走。前头那个点火的，是把尸烤干了"
  - **⑤ 提前读过古籍的玩家，或 ⑦ 记得井是干的的玩家，这一步会快得多**
- **术（只有理能指向）**：**灭火 + 泼水**。常识全在反方向，钱买不到"湿"
- **行动**：灭火（反直觉，玩家心里发虚）→ 野道没井，水在下面河沟，来回三趟 → **它在动**
- **三档**：
  - 有理有术 → 它软下去躺平，背回义庄。管事："这具躺半个月了，谁把它烤起来的？"（留钩）
  - 有理无术 → 灭了火它慢下来但没停，你跑了。**事没了结，它还在野道上**（后患：后面走野道会撞上）
  - 只有象 → 濒死 + 留痕
- **回写**：
  - **R9「白毛僵尸怕火」→ 推翻。** 本子上划掉，旁边留一句关二狗自己添的："说书的嘴，信不得。"
  - **R3「干尸才走」象理术三层齐 → 有效。这是他手里第一条自己验过的真货。**

> **剧情拐点**：说书先生的话是假的。关二狗"李天狗那一脉"的自我认知在这儿裂第一道缝——而他嘴上还得继续吹。

### ⑩ 义庄两尸 · **循环拍（R3 复用 + R4 对照实验）** ★ **玩法集大成**

**剧情不动**：管事来寻、被半推半架进门、两具尸扭打、镇尸、松手、克拉拉出场招募。

**玩法结构**：

**进门那一刻，R3 立刻兑现**
- 玩家揣着「干尸才走」走进义庄——**这两具是屋里停的，干的。**
- 玩家自己反应过来：**难怪。**（无需任何提示，这是复用的爽点）
- **而且 R3 的术在这儿用不了**——义庄里没有那么多水，两具尸也不是烤干的。**知道原因≠能解决**，这一下把"理不等于术"钉死

**R4 的对照实验（核心动作）**
- 玩家手里有 R4「镇尸四样」，术层**存疑**——"用过一回管用，但不知道是哪一样起的作用"
- **入口处玩家自己挑组合**：撒米？绷线？按石子？横剪子？**用几样？哪几样？**
- **为了搞清楚而故意少做一样**——这是全 Demo 手感最尖的一下
- **三档**：
  - 四样全下 → 一定成功，但 R4 术层**仍然存疑**（你还是不知道是哪样）
  - 少做一样且成功 → **R4 术层细化**（排除掉一样，本子上多一句"墨斗线好像不打紧"）
  - 少做一样且失败 → 外乡尸反扑 → **濒死 → 死亡系绳** → 但 R4 也细化了（"石子少不得"）
- **回写**：R4 术层按玩家的实验结果细化。**四样全下的玩家，本子里永远留着那句"不知道是哪一样"**——这是他自己选的安全，代价是永远不明白

**克拉拉招募**：剧情不动。她看见的是"念几句撒几样，两具僵尸就松开了"——**而玩家清楚地知道自己刚才在做对照实验，还不一定做对了**。这个不对称是招募那一幕全部的讽刺来源。

## 4. 与现状的冲突（按 §0 停下报告）

**冲突一：现有玩法资产大面积不再服务核心玩法。**
- 压力条 12 个实例（上肩/落凳/野道三关/喊名/逃跑/镇尸步）——本稿里**全部不作为玩法**。背尸改成路线判断，喊名改成方位判断，镇尸改成组合实验。
- 这不等于要删：它们可以**降级为表现层**（背尸时的体感、镇尸时的紧张），但**不再承担"玩法"的角色**。
- **需要你拍板**：是保留作表现，还是彻底移除。

**冲突二：⑦ 枯井、④ 河边被我定成"不做循环"。**
- 这两拍现在有完整的叙事编排，我判断给它们套象理术会毁掉恐怖。
- **需要你拍板**：接受它们只做播种，还是要求全 Demo 每拍都是循环。

**冲突三：假规矩的投放时机。**（2026-07-26 已修正，见 §0 原则四）
- 原稿把 R9 放在 ⓪ 听书 —— **错的**。玩家还没建立"规矩管用"的信任就给假货，会判定整套系统不可靠。
- 现方案：R9 投放在 **② 茶馆吹牛（说书人返场）**，此时玩家已验过 R2 和 R8，且正吹得得意。
- 残留风险：**仍有玩家会觉得被耍**。缓解靠 ⑨ 推翻那一刻立刻给足回报（R3 当场诞生 → ⑩ 进义庄立刻兑现），把"被骗"翻成"我进步了"。**这个补偿的即时性是硬要求，不能拖到正篇。**

**冲突四：规矩数据现状只有 8 条且多数只有象层。**
- 本稿的 9 条里，R2/R3/R8 是新的；R1/R4/R5/R6 要补理层和术层；R7 保留现状；R9 要加"可被推翻"的数据支持。
- 旧的 `rule_no_go_night` / `rule_ghost_verified` / `rule_ghost_origin`（城隍庙后山白影 / 柳家戏班）**不在寻狗 demo 流程内，疑似旧原型残留**。需要确认是废弃还是保留。

**冲突五：本稿要求的两项引擎能力尚不存在。**
- `NarrativeOwnerType` 加 `rule`
- 规矩正文随掌握状态换版本（R4 细化、R9 划掉都要用）
