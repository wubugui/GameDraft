# 物件检视（Object Examine）表现力与可玩性提升方案

> 日期：2026-07-30
> 分支：feat/object-examine-system
> 现状：一期已落地「静帧 + 矩形/多边形热区 + 上下文操作 + Action 结果」，见
> `src/systems/objectExamine/`、`docs/玩法功能需求清单.md` K4.6 节。
> 本文是可逐条试做的改进清单，按「低成本先做 → 中期演进」排序，每条标注改动面与验证方式。

## 参考案例

- 生化危机重制系物品检视：旋转/翻面后在背面发现信息，"操作出发现"是核心爽点
- Return of the Obra Dinn：线索互相锁定、死亡场景当构图照片呈现、发现入册（logbook）
- 纸嫁衣系：道具 × 场景矩阵、难度递进、民俗恐怖氛围资产（过于安静本身即氛围）
- L.A. Noire 验尸：每个可点处都有信息量 → 玩家退化为扫图穷举（反面教材）

## A. 低成本高回报（不动数据结构）

### A1. 热区特写镜头 ⭐ 优先

- 数据通道：热区/操作新增可选 `narration`（操作覆盖热区），演示实例三个热区已从 showNotification 迁到 narration；「继续」文案走 strings.objectExamine.continue。
- 改动面：`ObjectExamineScene.ts`（beginFocus/endFocus/drawFocusDim/layoutNarration）、`types.ts`、`ObjectExamineManager.ts`（continue 文案）、`strings.json`、demo JSON、`docs/玩法功能需求清单.md` K4.6。

### A2. 静帧微动效

- 做法：presentation 级别公共动效层：光源呼吸（烛光/月光光强缓变）、尘埃粒子、偶发小动（蝇虫掠过）、极缓视差漂移。做成公共配置，不逐实例调。
- 改动面：`ObjectExamineScene.ts` 渲染层；类型上加可选 `ambience` 字段（可缺省走默认）。
- 验证：静帧 30 秒内不显得"死"；性能无感。

### A3. 发现留痕 ⭐ 优先

- 问题：已发现热区只靠记忆和 allFound 判定，没有画面反馈。
- 做法：已发现热区在图上留记号（墨圈/朱砂点/划痕，题材定）；一眼可见"翻过几处"。
- 改动面：`ObjectExamineScene.ts`；记号样式走 strings/配置或常量。
- 验证：发现一个热区后图上立刻出现记号；退出重进会话内状态一致（一期会话内即可）。

### A4. 假热区 / 干扰反馈

- 问题：每个可点处都有信息量 → 玩家扫图穷举（L.A. Noire 教训）。
- 做法：支持"点了但没东西"的干扰点，配 flavor 反馈（"只是泥""看错了，是阴影"），偶尔吓一下。真发现因此显得是"看出来的"。
- 改动面：数据层热区可标 `decoy: true` 或直接复用 actions 写 flavor；Scene 对 decoy 不计入 found 进度。
- 验证：演示实例加 1-2 个干扰点；allFound 判定不受干扰点影响。

### A5. 音效分层

- 做法：hover 热区极轻摩擦声、点中低音 sting、会话全程环境音床（水滴/风/苍蝇）。系统当前全静音，性价比最高的恐怖放大器。
- 改动面：`ObjectExamineScene.ts` 接 AudioManager；音效 id 走配置。
- 验证：hover/点中/全程三层都有声；退出会话音床正确停止（资源 scope 回收）。

## B. 中期演进（顺着已有扩展位长）

### B1. presentation.kind 第二形态：`flip` / `layered`

- 依据：types.ts 已预留 kind 扩展位（"后续可扩 layered / flip 等 kind"）。
- `flip`：翻面（看尸体身下压着什么）——2D 等价于生化的"转过来发现背面刻字"。
- `layered`：掀开表层（衣角）露出下层，下层带新热区。"掀开"本身是民俗恐怖经典节拍。
- 改动面：types + Scene + validator + 编辑器；工程量最大的一项，单独排期。

### B2. 上下文操作范式化：感官 × 道具矩阵

- 做法：操作数据化为几类范式——
  - 感官类：看 / 摸 / 嗅 / 凑近听（听可配声纹或心跳可视化）
  - 道具类：用火折子照 / 银针试 / 糯米撒——背包有对应物品才出现
- 数据：operation 加 `requires`（flag / itemId），纯数据驱动。
- 验证：演示实例给一个热区配"需要火折子"操作；无道具时菜单不显示该项。

### B3. 热区依赖（浅推理树）

- 做法：`hs_A` 发现后解锁 `hs_B` 的某操作（看到脚踝勒痕 → "翻动裤脚"才有意义）。扁平热区列表变浅推理树，两三个依赖即产生"我在推理"体感（Obra Dinn 式线索互锁的轻量版）。
- 数据：hotspot/operation 加 `requiresFound: ["hs_A"]`。
- 验证：依赖未满足时操作隐藏或给"还看不出什么"反馈；满足后出现。

### B4. 结果接入档案系统（K5 四本书）⭐ 优先

- 问题：`objectExamine:result` 事件目前无人消费，找齐与否毫无后果。
- 做法：发现的线索自动落档案/线索页；后续对话可引用（"你注意到他脚跟发白"）。检视由此从孤立玩法变成叙事网络的信息源。
- 改动面：叙事侧订阅 `objectExamine:result` 或读 `lastResult`；档案系统写入入口。
- 验证：检视完成后档案出现对应条目；相关对话分支可读取。

### B5. 危险操作

- 做法：操作标 `risky`（或纯靠 actions 实现）：点了触发 jump scare / 掉状态 / 立剧情 flag（尸变引线）。"是否按下去"成为决策而非无脑全点。
- 验证：演示实例加一个 risky 操作；flag 正确落库、后续叙事可读。

## 建议试做顺序

1. **A1 特写镜头** — 表现力及格线的关键一跃
2. **A3 发现留痕** — 半小时级改动，反馈感立现
3. **B4 接档案** — 让玩法"有意义"，接上已有叙事骨架
4. A5 音效 → A2 微动效 → A4 干扰点（氛围打磨）
5. B2 道具矩阵 → B3 热区依赖（深度，等内容跑起来再上）
6. B1 flip/layered（单独排期的大件）

每条做完在演示实例 `demo_waterlogged_corpse` 上验证，再决定是否推广到正式内容。
