# 实体阴影与遮挡

## 一眼看全

$$
\text{影子} = \text{当前帧剪影}\ \xrightarrow{\ \text{按 (方向, 长度, 散开, 宽度) 剪切}\ }\ \text{贴在行走面上}\times\text{浓度}\ (\text{软度模糊})
$$

$$
\text{被前景遮挡} \iff d_{\text{scene}} + \mathrm{tolerance} < d_{\text{sprite}}
$$

- 影子往哪投**由作者绑定决定**（`light:<id>` / `virtual` / `none`），不自动解算；一条绑定一个影子。
- 方向、长度、浓度、软度、散开、宽度全由绑定的灯位解出。
- 脚底接触斑与灯无关，常驻。
- 遮挡把 sprite 当立在伪世界里的直立 quad，逐像素与场景深度比。

下面各节逐项拆开。

## 绑定

每个实体（玩家 `playerShadowBindings`、NPC / 热区 `shadowBindings`）是一组绑定：

| `source` | 含义 |
|---|---|
| `light:<id>` | 跟这盏真实灯 |
| `virtual` | 用 `virtual` 里给的方向、仰角、浓度、软度、长度；**只影响影子，不照亮角色** |
| `none` | 不投影 |

## 绑真实灯时的解算

$(l_x, l_y, l_z)$ = 灯位相对角色（胸口）的世界向量（wu → q）；平行光用 `elevationDeg` / `azimuthDeg` 的来向。

| 量 | 公式 | 含义 |
|---|---|---|
| 屏幕角 | 光的**水平**方向取反 → 经 $R^{\mathsf T}$ 回 $q$ → 投屏（$x = q_x$，$y = -q_y$） | 影子在屏幕上的倒向 |
| 仰角 | $\varepsilon = \arctan\dfrac{l_y}{\sqrt{l_x^2 + l_z^2}}$，钳在区间内 | |
| 长度 | $\mathrm{clamp}\!\big(\dfrac{\mathrm{aniso}}{\tan\varepsilon}\big)\cdot \mathrm{lengthScale}$，$\ \mathrm{aniso} = \dfrac{\lvert\mathrm{proj}(\text{地面水平单位向量})\rvert}{\lvert\mathrm{proj}(\text{世界竖直单位向量})\rvert}$ | 相对角色身高的倍率；aniso 补回斜地面的屏幕各向异性 |
| 浓度 | $\dfrac{e_{\text{此灯}}}{\ I_{\text{sky}} + \sum_{\text{所有开着的灯}} e\ }$，$\ e = I\cdot \dfrac{\exp(-r^2/\mathrm{range}^2)}{r^2 + c}$（平行光 $e = I$） | 这盏灯占全部照明的份额；$I_{\text{sky}}$ = `lighting.sky.intensity` |
| 软度 | 与光源角尺寸成正比：$\dfrac{\text{灯体半径 或 面光半对角}}{\text{距离}}$，钳在区间内；平行光最硬 | |
| 散开 | $\dfrac{1+u}{1-u}$，$u = \dfrac{\text{半身高}}{l_y}$（平行光 $u=0$） | 点光下头端放大（平行四边形 → 梯形） |
| 宽度 | $\sqrt{h_z^2 + (b\,h_x)^2}$，$(h_x,h_z)$ = 光的水平单位方向，$b$ = 体厚比 | 迎光截面：侧光时压窄到体厚 |

`darkness` / `softness` 写了就覆盖上表对应项。灯关着或查不到 ⇒ 这条不投影。同样的输入永远同样的输出，逐帧幂等。

## 剪影修正

- 末端渐隐：从影长的某位置起浓度向末端收。
- 半影随距离展宽：采样半径从脚端 0 长到头端。
- 落地面：逐像素取行走面深度场 `ground_d.png`。
- 碰撞方向阻挡、前景深度混合：影子被前景遮住的部分按深度混合。

## 脚底接触斑

与灯**无关**，常驻。椭圆 quad，大小与浓度由光照环境的 `shadow.contact` / `shadow.contactSize` 控制（`game_config.entityLighting.defaultLightEnv`，场景 `lightEnv` 可覆盖），只压暗，不做碰撞与遮挡。

## 深度遮挡

$$
d_{\text{sprite}}(s_y) = d_{\text{foot}} + \frac{\tan\theta}{\mathrm{ppu}}\,(s_y - s_{y,\text{foot}}) + \mathrm{floorOffset} - \mathrm{footBias}
$$

| 符号 | 含义 |
|---|---|
| $d_{\text{foot}}$ | 脚点处行走面深度场 `ground_d.png` 的采样值 |
| $\theta$ | 相机俯仰角（标定） |
| $s_y - s_{y,\text{foot}}$ | 该像素相对脚点的纵向像素差（越靠上越近相机） |
| $d_{\text{scene}}$ | 该像素处场景深度图解码值 |
| $\mathrm{tolerance}$ | 深度容差 |

被遮挡像素按 `occlusionBlendFactor` 乘 alpha（0 = 直接丢弃）。**没有行走面深度场 ⇒ 整段不遮挡。**

## 输入 → 输出

| 输入 | 用途 |
|---|---|
| 场景灯 `lighting.lights` + `sky.intensity` | 绑定解算 |
| 实体的 `shadowBindings` / `playerShadowBindings` | 影子方向、浓度 |
| `depthConfig.M.R`、`wuPerQUnit` | 世界 ↔ q ↔ 屏幕 |
| `ground_d.png` | 影子落地面、脚点深度 |
| `raw_depth_rg.png` | 深度遮挡的场景深度 |
| `collision.png` | 影子的碰撞方向阻挡 |
| 光照环境 `lightEnv`（`game_config.entityLighting.defaultLightEnv` ⊕ 场景 `lightEnv`）的 `shadow` | 模式（planar / off）、接触斑 |

| 输出 |
|---|
| 每条绑定一个投影剪影 quad + 一个接触斑 quad |
| 被前景遮住的 sprite 像素被裁掉 |
