# 光照数据与文件

## 一眼看全

```text
场景 JSON  <id>.json
├─ lighting            灯、雾、显示变换、自发光、shadowBias        ← 作者写
├─ timeVariants[时段]  该时段换哪张原画 / 环境块覆盖                ← 作者写
├─ shadowBindings      每个实体的影子绑定                          ← 作者写
└─ depthConfig         M.R · ppu · cx · cy · depth_mapping           ← 实验室导出

runtime/scenes/<id>/
├─ <背景>.png          原画（每个时段一张）
├─ raw_depth_rg.png    深度图                                       ← 实验室导出
├─ collision.png       碰撞格                                       ← 实验室导出
└─ lighting/<背景基名>/  这张原画的全部光照派生物
   ├─ lighting.json · atlas_*.bin · probes_valid.bin · ground_d.png   ← 实验室导出（角色照明）
   └─ geometry.json · normal.png · albedo.png · skyao_probe.bin       ← 几何场烘焙器（场景照明）
```

下面逐块列字段。

## 场景 JSON

### `lighting` 块

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `sky.intensity` | 数 | — | 实体影子浓度解算的环境照度分母 |
| `lights[]` | 数组 | — | 实体灯，见下表 |
| `fog.sigma` | 数 | 1/wu | 基准消光系数 $\sigma_0$ |
| `fog.scaleHeight` | 数 | wu | 高度衰减尺度 $H$ |
| `fog.baseHeight` | 数 | wu | 雾的基准高度（相对地面） |
| `fog.kelvin` / `fog.color` | 数 / RGB | K / 线性 | 雾色，二选一，`color` 赢 |
| `fog.scatter` | 数 | — | 散射强度（雾自身亮度） |
| `display.ev` | 数 | 档 | 曝光 $2^{\mathrm{ev}}$ |
| `display.tonemap` | `none` / `reinhard` / `filmic` | — | tonemap 曲线 |
| `display.whiteKelvin` | 数 | K | 白平衡 |
| `display.contrast` | 数 | — | 对比（以 0.18 中灰为轴） |
| `display.saturation` | 数 | — | 饱和 |
| `display.lift` | 数 | — | 暗部提升强度 |
| `display.liftKelvin` | 数 | K | 暗部提升的颜色 |
| `emissive.gain` | 数 | — | 灯体自发光增益；0 = 灯只照亮不发光 |
| `emissive.coreRadius` | 数 | wu | 灯体半径 $R_c$ |
| `emissive.haloRadius` | 数 | wu | 光晕半径 $R_h$ |
| `emissive.haloGain` | 数 | — | 光晕相对灯体的强度 |
| `shadowBias.bias` | 数 | wu | 阴影线扫的起步偏置 |

`fog` 与 `emissive` 可缺省；`sky`、`display`、`lights` 必须存在。配了 `lighting` 的场景必须有 `depthConfig`，否则运行时不启用。

### 一盏灯 `lights[i]`

| 字段 | 类型 | 单位 / 空间 | 适用 kind | 含义 |
|---|---|---|---|---|
| `id` | 字串 | — | 全部 | 灯的 id；影子绑定用 `light:<id>` 引用它 |
| `kind` | `point` / `spot` / `area` / `directional` | — | 全部 | 类型 |
| `enabled` | 布尔 | — | 全部 | 初始是否点亮；运行时可由 action 改 |
| `phases` | 字串数组 | — | 全部 | 时段归属；不写 = 全时段亮；值须是 `game_config.dayNight.phases` 的 id |
| `pos` | $[x,y,z]$ | wu，M-world，原点 = 世界原点 | point / spot / area | 灯位 |
| `kelvin` / `color` | 数 / RGB | K / 线性 | 全部 | 颜色，二选一，`color` 赢 |
| `intensity` | 数 | — | 全部 | 强度 $I$ |
| `range` | 数 | wu | point / spot / area | 作用半径（高斯截断） |
| `softeningRadius` | 数 | wu | point / spot | 发光体半径；进 $1/(r^2 + c)$ 时取平方 |
| `castShadow` | 布尔 | — | point / spot / area | 是否投影（走线扫遮挡） |
| `dir` | $[x,y,z]$ | M-world | spot | 射出方向 |
| `innerAngleDeg` / `outerAngleDeg` | 数 | 度 | spot | 内外锥角，$0 < \text{内} \le \text{外} < 90$ |
| `size` | $[w,h]$ | wu | area | 矩形宽高 |
| `orientation` | $[x,y,z]$ | M-world | area | 矩形法线（发光面朝向） |
| `rollDeg` | 数 | 度 | area | 绕自身法线的自转 |
| `twoSided` | 布尔 | — | area | 双面发光 |
| `elevationDeg` / `azimuthDeg` | 数 | 度 | directional | 光的**来向** |

### 时段外观 `timeVariants[<时段 id>]`

只写与白天（场景顶层）不同的项，没写的沿用顶层。

| 字段 | 含义 |
|---|---|
| `backgrounds` | 该时段换成哪张原画 |
| `lighting` | 环境块**整块**覆盖（sky / fog / display / emissive / shadowBias），按顶层键整块替换。**不含 `lights`** —— 灯按各自 `phases` 过滤 |
| `depthConfig` | 该时段另一套深度 / 碰撞，只在夜是完全另一张图时用 |
| `ambientSounds` / `bgm` / `filterId` | 写了就整个替换 |

### 影子绑定

玩家：场景 JSON 顶层 `playerShadowBindings[]`；NPC / 热区：各自实体上的 `shadowBindings[]`。一条：

| 字段 | 含义 |
|---|---|
| `source` | `light:<id>` / `virtual` / `none` |
| `virtual.azimuthDeg` | **屏幕**方向 |
| `virtual.elevationDeg` | 仰角 |
| `virtual.darkness` / `virtual.softness` | 浓度 / 软度 |
| `virtual.length` | 影长（wu）；0 或不填 = 按仰角算 |
| `darkness` / `softness` | 覆盖解算值 |
| `lengthScale` | 影长倍率 |

### 几何契约 `depthConfig`

| 字段 | 含义 |
|---|---|
| `M.R` | $3\times3$，$q \to$ M-world，$\det = +1$ |
| `M.ppu` / `M.cx` / `M.cy` | 标定：每 q 单位多少原生像素、主点 |
| `depth_mapping.invert` / `scale` / `offset` | 深度图解码 $d = t\cdot\mathrm{scale} + \mathrm{offset}$ |

## 场景运行时目录 `runtime/scenes/<id>/`

| 文件 | 内容 |
|---|---|
| `<背景>.png` | 原画（每个时段一张） |
| `raw_depth_rg.png` | 深度图，RG16 |
| `collision.png` | 碰撞格 |
| `lighting/<背景基名>/` | 该张原画的全部光照派生物，见下 |

**烘焙产物按第一层背景图名索引**：换时段 = 换主背景 = 换一整套 `lighting/<背景基名>/`，每张时段原画各烘一份。唯一例外是 `albedo.png`：按**主背景**算一次，各时段目录放同一份字节。

## 烘焙目录 `lighting/<背景基名>/`

| 文件 | 内容 | 格式 | 生产者 | 消费者 | 发行包 |
|---|---|---|---|---|---|
| `lighting.json` | 标定 / 世界盒 / probe 网格 / 光源 / shading 参数 / `background_sha1` | JSON | 实验室「导出照明」 | 角色照明 | 必带 |
| `atlas_bin.bin` | probe 图集，八面体 bins（`shading.mode` = 3） | f16 RGBA | 实验室 | 角色照明 | 当前 mode 那一份必带 |
| `atlas_l2.bin` / `atlas_l1.bin` | probe 图集，球谐 L2 / L1（mode 2 / 1） | f16 RGBA | 实验室 | 角色照明 | 非当前 mode 只进 dev 档 |
| `probes_valid.bin` | probe 有效掩码，每颗 0 / 255 | u8 | 实验室 | 角色照明 | 必带 |
| `ground_d.png` | 行走面深度场 | RG16，work 分辨率 | 实验室 | 角色脚点、影子落地面、深度遮挡、碰撞反投影 | 必带 |
| `skyao_probe.bin` | 天穹遮蔽矩 $(a_0, a_1)$ | f16 ×4，Z 切片平铺 | 几何场烘焙器 | 角色照明 | 有就带 |
| `geometry.json` | 几何场元数据，见下 | JSON | 几何场烘焙器 | 场景光照、摆灯 | 必带 |
| `normal.png` | 世界法线 | RGB8 | 几何场烘焙器 | 场景光照 | 必带 |
| `albedo.png` | 反照率贴图，**作者可手改** | sRGB8，原生分辨率 | 几何场烘焙器 | 场景光照 | 必带 |
| `skyvis.png` | 逐像素天穹可见性 | R8 | 几何场烘焙器 | 只作 `albedo.png` 的离线输入 | 不带 |
| `vol_rad.bin` / `vol_emit.bin` | 体素辐射卷 / 发光卷 | f16 RGBA，Z 切片平铺 | 实验室 | 只有 F2 切到 RT 档才读 | 只进 dev 档 |

缺 `lighting.json` / `probes_valid.bin` / `ground_d.png` / 当前 mode 图集之一 ⇒ 整份载荷作废（角色不打光 + 行走面场丢）。缺 `geometry.json` / `normal.png` / `albedo.png` 之一 ⇒ 场景侧光照不启用。

### `lighting.json`

| 字段 | 含义 |
|---|---|
| `version` | 载荷代次 |
| `background_sha1` | 烘焙时原画的哈希（短） |
| `work.{w,h}` | 工作分辩率 |
| `cal.{theta, ppu, cx, cy}` | 工作分辩率下的标定；`theta` = 相机俯仰角 |
| `world.M` | $q \to$ probe 世界，$\det = -1$ |
| `world.{x0,x1,y0,y1,z0,z1}` | probe 世界盒 |
| `probes.{nx,ny,nz}` | probe 网格 |
| `probes.sh_lmax` / `sh_k` / `bin_ob` | 球谐阶数 / 系数数 / 八面体边长 |
| `vol.*` | 体素卷维度、平铺、q 值域 |
| `ambient_sh` | 环境闭合球谐 |
| `lights[]` | 烘焙期提取的光源 `{pos, radiance, area}` |
| `ground_d.{min,max}` | `ground_d.png` 的解码区间 |
| `shading.{mode, spp, step, msteps, fold, miss_mode, nee, beta, amb, bulge, flatten}` | 着色参数（导出时的面板值） |

### `geometry.json`

| 字段 | 含义 |
|---|---|
| `version` | 几何场载荷代次 |
| `background_sha1` / `depth_sha1` | 原画 / 深度图的哈希 |
| `work.{w,h}` / `native.{w,h}` | 两套分辩率 |
| `cal.{ppu,cx,cy}` | 原生分辨率标定 |
| `grid.{nx,ny,nz,…}` | 几何场网格与盒 |
| `char_wu` / `cell_wu` / `cells_per_char_*` / `height_chars` / `band` / `scene_per_wu` | 网格尺度 |
| `day_hemi` | 原画自身的遮蔽响应，albedo 反解的除数参数 |
| `skyao_probe.{file, channels, dtype, layout, eval, frame, spp}` | 天穹遮蔽矩的存储与求值说明 |
| `albedo_map.file` | `albedo.png` |
| `albedo_map.formula` | $\mathrm{clamp}\big(\mathrm{linear}(\text{主背景}) / ((1 - \mathrm{day\_hemi}) + \mathrm{day\_hemi}\times\mathrm{skyvis}),\ 0,\ 1\big)$ |
| `albedo_map.encoding` | sRGB8 |
| `albedo_map.from_background` / `source_sha1` | 从哪张主背景算的、当时的哈希 |
| `albedo_map.authored` | `true` = 作者手改过，重烘不覆盖 |
