# 角色受光

## 一眼看全

角色是一个 billboard sprite，颜色图集的像素当 albedo，逐像素：

$$
\mathrm{screen} = \mathrm{Display}\Big(\mathrm{srgb2lin}(a)\cdot\frac{E'}{\pi}\cdot 2^{\beta}\Big)\cdot\mathrm{AO}
\qquad\qquad
E = \underbrace{E_{\text{probe}}\cdot g_{\text{GI}}\cdot V_{\text{skyao}}}_{\text{烘出来的底光}} + \underbrace{\sum_i E_i}_{\text{实体灯}}
$$

| 符号 | 是什么 |
|---|---|
| $a$ | 颜色图集像素 |
| $E_{\text{probe}}$ | probe 烘出来的 GI 底光（按位置与法线查表） |
| $V_{\text{skyao}}$ | 天穹遮蔽 $[0,1]$ |
| $\sum_i E_i$ | 场景实体灯，与场景**同一次打包**，公式同[场景受光](02-场景受光.md) |
| $E'$ | $E$ 按色度权重与自身亮度混合后的值 |
| $\beta$ | 曝光指数 |
| $\mathrm{Display}$ | 与背景**同一份**显示变换、同一组参数 |
| $\mathrm{AO}$ | sprite 空间的接触 / 形体 AO |

下面各节逐项拆开。

## 着色式

$$
\mathrm{col}_{\text{lin}} = \mathrm{srgb2lin}(a)\cdot \frac{E'}{\pi}\cdot 2^{\beta},\qquad
E' = \mathrm{mix}\big(\mathrm{luma}(E),\ E,\ \chi\big),\qquad
\mathrm{AO} = 1 - \mathrm{contact}\cdot\mathrm{smoothstep}(v) - \mathrm{form}\cdot v
$$

| 符号 | 含义 | 单位 / 空间 |
|---|---|---|
| $a$ | 颜色图集像素（sRGB，Pixi 预乘已除回） | — |
| $\chi$ | E 色度权重：0 = 只借场景明暗、角色保留自己的颜色；1 = 完整彩色 E | — |
| $\beta$ | 曝光指数，角色曝光唯一旋钮 | — |
| $v$ | 帧内纵向坐标（0 顶 1 脚） | — |
| $\mathrm{contact}$ / $\mathrm{form}$ | 接触 AO / 形体 AO 强度 | — |

## $E$ 的组成

$$
E = E_{\text{probe}}(q, n)\cdot g_{\text{GI}}\cdot \mathrm{mix}\big(1,\ V_{\text{skyao}}(q,n),\ b\big) \;+\; \sum_i E_i
$$

| 符号 | 含义 | 单位 / 空间 |
|---|---|---|
| $E_{\text{probe}}(q,n)$ | probe 底光在角色位置、法线 $n$ 处的辐照度 | 线性 RGB；$q$、$n$ 在伪世界 $q$ 空间进查表 |
| $g_{\text{GI}}$ | GI 底光增益，只乘 $E_{\text{probe}}$ | — |
| $V_{\text{skyao}}(q,n)$ | 天穹遮蔽，1 = 不遮蔽；无 `skyao_probe.bin` 时恒 1 | — |
| $b$ | skyao 混合强度 $[0,1]$ | — |
| $E_i$ | 场景实体灯，$\mathrm{vis}\equiv 1$（角色侧不做灯的遮挡） | 在 M-world 算，wu |

## 每像素的几何

- 位置：由 sprite 顶点变换直接给出脚点与世界坐标，再进 $q$；采样点沿深度轴按 `bulge` 鼓起。
- 法线 $n$：法线图集 `<图集名>.normal.png`，与颜色帧**同一套 UV**；`flatten` 压平量。镜像由变换行列式判定。
- 实体灯用的 $P$、$N$ 与场景侧同式：$P = (R\cdot q)\cdot\mathrm{wuPerQUnit}$，$N = R\cdot n$。

## $E_{\text{probe}}$：probe 查表

probe 是规则三维网格 `probes.{nx,ny,nz}`，覆盖世界盒 `world.{x0..z1}`，8 个角三线性加权：

$$
X_w = M_{\text{lab}}\cdot q,\qquad
\text{格坐标} = (X_w - X_{\min})\cdot S,\qquad
\text{flat} = i_x\,(n_y n_z) + i_y\,n_z + i_z
$$

无效格（`probes_valid.bin` = 0）不参与。每颗 probe 按 `lighting.json` 的 `shading.mode` 存三种编码之一：

| mode | 图集 | 每颗 probe 的编码 | 求值 |
|---|---|---|---|
| 3 | `atlas_bin.bin` | 八面体 bins，边长 `probes.bin_ob`（8 ⇒ 64 方向，16 ⇒ 256 方向） | $n \to$ 八面体坐标 $\to$ 双线性取 4 个 bin |
| 2 | `atlas_l2.bin` | 球谐 L2（`probes.sh_k` 个系数） | $\sum_k c_k\,Y_k(n)$ |
| 1 | `atlas_l1.bin` | 球谐 L1（4 系数） | 同上 |

图集为 f16 RGBA，列块 $[\,\mathrm{base}{+}\mathrm{cov}\mid\mathrm{amb}\mid\mathrm{emit}\mid\mathrm{nee}\,]$。

## $V_{\text{skyao}}$：天穹遮蔽

`skyao_probe.bin` 每格存遮蔽矩 $(a_0, a_{1x}, a_{1y}, a_{1z})$（f32），按任意法线求值：

$$
V(N) = \mathrm{clamp}\!\left(\frac{a_0 + a_1\cdot N_w}{\mathrm{cap}(N_w)},\ 0,\ 1\right),\qquad
\mathrm{cap}(N_w) = \frac{1 + N_{w,y}}{2}
$$

$N_w$ 是法线转到 `depthConfig.M.R`（$\det=+1$）那套世界。矩在网格上三线性插值。

## 输入 → 输出

| 输入 | 内容 |
|---|---|
| `lighting/<背景基名>/lighting.json` | 标定 `cal`、`world.M` 与世界盒、`probes` 网格、`shading` 参数、`ground_d` 值域、`background_sha1` |
| `atlas_bin.bin` / `atlas_l2.bin` / `atlas_l1.bin` | 当前 `shading.mode` 那一份 probe 图集 |
| `probes_valid.bin` | probe 有效掩码 |
| `ground_d.png` | 行走面深度场（脚点深度） |
| `skyao_probe.bin` | 天穹遮蔽矩（可选） |
| 角色颜色图集 + `<图集名>.normal.png` | albedo 与法线，同 UV |
| 同一次打包的灯 + `depthConfig.M.R` | 实体灯项 |
| 场景 `display` | 显示变换参数 |

| 输出 | 内容 |
|---|---|
| 屏幕 | 着色后的 sprite（线性 → 显示变换 → sRGB） |

场景没有载荷、或 `background_sha1` 与当前背景失配时，几何项照用、光照项标 stale。
